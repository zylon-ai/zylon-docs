## Zylon Code 0.1

This manual covers the Desktop application, its English and Spanish interface, Zylon model connection, included modes and optional integrations. The initial mode is Standard and the Zylon connection starts with `zylon/default`.

Use [Availability](/zylon-code/reference/availability) to check prerequisites for a feature. Download locations and installation details will be added to [Installation](/zylon-code/getting-started/installation) with the client distribution information.

## Before updating

Record the application and installed plugin versions. Quit Zylon Code completely and back up its data and your project files. Read the release's changes and any migration instructions.

After updating, check representative conversations, credentials, attachments and enabled plugins. Keep originals until you have confirmed the update works. Custom bundles may need compatibility changes; retain their source and installation instructions.

This page describes the documented baseline. Release dates, download links and update procedures should come from the distribution record supplied with each client build.
