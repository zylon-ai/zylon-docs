Once a Skill is available in your project, you can bring it into any conversation from the chat message box.

## Steps

1. Start typing in the message box, then click the **+** button.
2. Select **Skills**.
3. Pick one or more Skills from the list.

![The Skills option inside the chat message box menu](/images/user-manual/skills/chat-plus-menu.png)

![Choosing a Skill from the project's list](/images/user-manual/skills/chat-skills-submenu.png)

Selected Skills appear as chips above the message box. Click the **×** on a chip to remove it before sending.

![A Skill selected and ready to use in a chat message](/images/user-manual/skills/chat-skill-selected.png)

---

## Turning a Skill on by default

If a Skill should apply to every new chat in a project — without picking it manually each time — a project admin can turn on **Enable on chat by default** for it from the project's **Skills** page.

<Info>
You can select more than one Skill in the same message. Zylon uses all of them together to shape its response.
</Info>
