<Warning>
**API breaking changes in 1.58**

Before upgrading an integration from 1.57, follow the [API migration guide](/en/v1.58/developer-manual/build-with-zylon/workspace-api/api-migration-1-57-to-1-58). Version 1.58 changes artifact routes and content payloads, account and workspace-member IDs, and server-tool response blocks in Workspace and ZylonGPT messages. Legacy routes do not preserve the complete 1.57 contract and are deprecated, with removal planned for 1.59.
</Warning>
