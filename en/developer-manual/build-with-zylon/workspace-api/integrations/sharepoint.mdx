SharePoint integrations are stored as artifacts. The integration identifier used by these endpoints is the integration artifact ID.

## Prerequisites

Enable SharePoint at the instance level first. See [SharePoint integration setup](/en/operator-manual/knowledge-base/sharepoint).

Create or reconnect the integration through the login flow documented in [OpenID & OAuth](/en/developer-manual/build-with-zylon/workspace-api/authentication/openid). Use the artifact endpoints below after OAuth creates the integration artifact.

## Get a SharePoint integration

This endpoint returns public artifact metadata. It never returns access tokens, refresh tokens, or other private properties.

<Accordion title="Endpoint parameters">
| Type | Name | Required | Notes |
| --- | --- | --- | --- |
| Path | `integrationArtifactID` | Yes | SharePoint integration artifact identifier. |
</Accordion>

```bash
curl "https://{BASE_URL}/api/v1/app/artifact/{integrationArtifactID}" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}"
```

## Start a SharePoint ingest

The endpoint returns a server-sent event (SSE) stream. Each selected item needs both its SharePoint drive ID and item ID.

<Accordion title="Endpoint parameters">
| Type | Name | Required | Notes |
| --- | --- | --- | --- |
| Path | `integrationArtifactID` | Yes | SharePoint integration artifact identifier. |
| Body | `project_id` | Yes | Destination project identifier. |
| Body | `items` | Yes | SharePoint items to ingest. |
| Body | `items[].drive_id` | Yes | Drive identifier containing the item. |
| Body | `items[].id` | Yes | SharePoint item identifier. |
</Accordion>

```bash
curl -N -X POST "https://{BASE_URL}/api/v1/app/artifact/{integrationArtifactID}/ingest" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}" \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{
    "project_id": "{projectID}",
    "items": [
      {
        "drive_id": "drive_b7e4c102",
        "id": "item_9d2a50f1"
      }
    ]
  }'
```

<Accordion title="Example stream">
```text
event: SyncEvent
data: {"type":"sync_started","current_artifact_count":18,"integration_item_count":64}

event: SyncEvent
data: {"type":"sync_completed"}
```
</Accordion>

## Errors and edge cases

- **400**: invalid SharePoint item or ingest parameters.
- **403**: integration not enabled or missing permission.
- **404**: integration artifact or project not found, or they do not belong together.
