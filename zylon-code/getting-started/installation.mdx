Zylon Code is distributed as a compiled Desktop application. You do not need to clone its source repository or install Node, Python or a package manager to install it.

<Note>
The download location and installation steps will be added here when the client distribution is ready. Until then, use the application build and instructions supplied by your Zylon contact.
</Note>

## Before you start

Have a project folder ready. To connect through your organization's Zylon gateway, ask its administrator for the **Base URL** and a **Gateway developer token**. The application can open before a model is configured.

## Open the application

Open Zylon Code and complete the welcome setup. New installations start in Spanish; you can select English in **Settings → General**. You should see the project chooser, conversation area and Settings.

Closing the main window can leave the application running in the background. Use the operating system's **Quit** action when you want to stop it completely.

Continue with [Connect to Zylon](/zylon-code/getting-started/connect-to-zylon). If the application does not open, see [startup troubleshooting](/zylon-code/troubleshooting/setup-and-models).
