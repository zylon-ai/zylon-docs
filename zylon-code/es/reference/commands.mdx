Escribe `/` o pulsa **+** para abrir el menú de comandos. Las opciones dependen del modo y los plugins activos. Las habilidades comparten el menú, aunque son instrucciones de una tarea y no comandos de la aplicación.

| Comando o acción | Para qué sirve |
| --- | --- |
| `/model` | Seleccionar un modelo entre los proveedores configurados. |
| `/permission` | Elegir los permisos de la conversación actual. |
| `/plan` | Planificar una tarea en un modo compatible. |
| `/goal` | Añadir o gestionar un objetivo. |
| `/compact` | Reducir el contexto activo mediante un resumen, cuando el modo lo admite. |
| `/export` | Exportar la conversación seleccionada. |
| `/feedback` | Abrir la opción de comentarios disponible. |
| `/nombre-habilidad` | Cargar una habilidad instalada que permita invocación por el usuario. |
| Adjuntar archivo | Añadir un archivo desde el menú de mensajes. |

## Utiliza un comando

Selecciona una opción y sigue su formulario o selector. Algunos comandos actúan directamente y otros necesitan parámetros. Si aparece un error, revisa el mensaje y el borrador antes de volver a enviarlo.

Solo algunos comandos aceptan adjuntos. Si uno los rechaza, conserva el archivo y envíalo en un mensaje normal o elige un comando que los admita. Si una habilidad comparte nombre con un comando integrado, prevalece el comando.

Los nombres literales, como `/model`, no cambian aunque sus etiquetas aparezcan en español. Los plugins pueden añadir más comandos; utiliza las sugerencias de tu aplicación para ver cuáles están disponibles.
