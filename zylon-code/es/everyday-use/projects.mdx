Un proyecto es una carpeta de tu ordenador. Zylon Code agrupa sus conversaciones y utiliza esa carpeta como directorio de trabajo de las herramientas. Añadir un proyecto registra la carpeta; no sube el repositorio ni crea un proyecto en Zylon Workspace.

## Añade un proyecto

1. Abre el selector desde la bienvenida o la barra lateral.
2. Selecciona una carpeta existente.
3. Comprueba su ruta completa e inicia una conversación.

Si trabajas con Git, elige la raíz del repositorio para que el agente pueda encontrar sus instrucciones, código y pruebas.

## Organiza el trabajo

El menú del proyecto permite cambiar el nombre que se muestra o quitarlo de la lista. Quitar la entrada no borra la carpeta. Puedes agrupar los chats por proyecto o verlos en una sola lista. Fija los importantes y busca los demás por su título.

Elige **Orden manual** para colocar las entradas a tu gusto o **Última actualización** para ver primero el trabajo reciente. Cambiar la opción de ordenación puede sustituir tu distribución manual guardada.

## Comprueba la carpeta seleccionada

Si no tienes claro dónde está trabajando el agente, pide:

> Muestra el directorio de trabajo y los archivos de su carpeta principal. No cambies nada.

Contrasta la ruta con el proyecto seleccionado. Si no coincide, inicia una conversación en el proyecto correcto. Continúa con [Conversaciones](/zylon-code/es/everyday-use/conversations).
