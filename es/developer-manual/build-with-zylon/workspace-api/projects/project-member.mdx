---
title: "Miembros del proyecto"
description: "Agrega, actualiza y elimina miembros de un proyecto."
---

Usa estos endpoints para controlar quién puede acceder a un proyecto y qué rol tiene. Roles: `Viewer`, `Commenter`, `Editor`, `Admin`, `Owner`.

Las respuestas de miembro del proyecto usan el ID del miembro del espacio de trabajo en `id` e incluyen la cuenta relacionada en `account`.

## Solicitud básica y respuesta

Lista miembros actuales con `GET /api/v1/app/project/{projectId}/member`.

<Accordion title="Parametros del endpoint">
| Tipo | Nombre | Requerido | Notas |
| --- | --- | --- | --- |
| Path | `projectID` | Si | Identificador del proyecto. |
| Query | `page` | No | Numero absoluto de pagina, empezando en 1. |
| Query | `page_size` | No | Numero de elementos por pagina. Predeterminado `20`. |
| Query | `page_order` | No | `ASC` o `DESC`. Predeterminado `ASC`. |
| Query | `after` | No | Cursor o valor desde el que paginar hacia delante. |
| Query | `before` | No | Cursor o valor desde el que paginar hacia atras. |
| Query | `first` | No | Limita a los primeros N elementos tras un cursor. |
| Query | `last` | No | Limita a los ultimos N elementos antes de un cursor. |
| Query | `total_count` | No | Incluye el total en la respuesta. |
</Accordion>

```bash
curl "https://{BASE_URL}/api/v1/app/project/{projectID}/member?page=1&page_size=50&total_count=true" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}"
```

<Accordion title="Ejemplo de respuesta">
```json
{
  "data": [
    {
      "id": "{wsMemberId}",
      "role": "Owner",
      "account": {
        "id": "{accountId}",
        "state": "Active",
        "email": "sasha@example.com",
        "name": "Sasha Patel",
        "profile_picture": "https://{BASE_URL}/files/profile-picture.png",
        "provider": "Credentials",
        "roles": ["Workspace"],
        "created_at": "2026-01-10T09:00:00Z",
        "updated_at": "2026-02-08T14:12:45Z"
      },
      "is_project_member": true
    }
  ],
  "has_next_page": false,
  "has_previous_page": false,
  "total_count": 1
}
```
</Accordion>

## Agregar miembros

<Accordion title="Parametros del endpoint">
| Tipo | Nombre | Requerido | Notas |
| --- | --- | --- | --- |
| Path | `projectID` | Si | Identificador del proyecto. |
| Body | `members` | Si | Lista de miembros a agregar. |
| Body | `members[].ws_member_id` | Si | Identificador del miembro del espacio de trabajo. |
| Body | `members[].role` | Si | `Viewer`, `Commenter`, `Editor`, `Admin` u `Owner`. |
</Accordion>

```bash
curl -X POST "https://{BASE_URL}/api/v1/app/project/{projectID}/member" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}" \
  -H "Content-Type: application/json" \
  -d '{
    "members": [
      { "ws_member_id": "{wsMemberId}", "role": "Editor" }
    ]
  }'
```

<Accordion title="Ejemplo de respuesta">
```json
[
  {
    "id": "{wsMemberId}",
    "role": "Editor",
    "account": {
      "id": "{accountId}",
      "state": "Active",
      "email": "jordan@example.com",
      "name": "Jordan Lee",
      "profile_picture": "https://{BASE_URL}/files/profile-picture.png",
      "provider": "Credentials",
      "roles": ["Workspace"],
      "created_at": "2026-01-10T09:00:00Z",
      "updated_at": "2026-02-07T09:20:12Z"
    },
    "is_project_member": true
  }
]
```
</Accordion>

## Actualizar roles de miembros

<Accordion title="Parametros del endpoint">
| Tipo | Nombre | Requerido | Notas |
| --- | --- | --- | --- |
| Path | `projectID` | Si | Identificador del proyecto. |
| Body | `members` | Si | Lista de miembros a actualizar. |
| Body | `members[].ws_member_id` | Si | Identificador del miembro del espacio de trabajo. |
| Body | `members[].role` | No | `Viewer`, `Commenter`, `Editor`, `Admin` u `Owner`. |
| Body | `members[].is_pinned` | No | Fija o desfija el proyecto para ese miembro. |
</Accordion>

```bash
curl -X PUT "https://{BASE_URL}/api/v1/app/project/{projectID}/member" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}" \
  -H "Content-Type: application/json" \
  -d '{
    "members": [
      { "ws_member_id": "{wsMemberId}", "role": "Admin", "is_pinned": true }
    ]
  }'
```

<Accordion title="Ejemplo de respuesta">
```json
[
  {
    "id": "{wsMemberId}",
    "role": "Admin",
    "account": {
      "id": "{accountId}",
      "state": "Active",
      "email": "jordan@example.com",
      "name": "Jordan Lee",
      "profile_picture": "https://{BASE_URL}/files/profile-picture.png",
      "provider": "Credentials",
      "roles": ["Workspace"],
      "created_at": "2026-01-10T09:00:00Z",
      "updated_at": "2026-02-07T09:20:12Z"
    },
    "is_project_member": true
  }
]
```
</Accordion>

## Obtener o quitar un miembro

Usa `me` en lugar de `wsMemberId` para dirigirte al miembro autenticado del espacio de trabajo.

<Accordion title="Parametros del endpoint">
| Tipo | Nombre | Obligatorio | Notas |
| --- | --- | --- | --- |
| Path | `projectID` | Si | Identificador del proyecto. |
| Path | `wsMemberId` | Si | ID del miembro, o `me` para el miembro autenticado. |
</Accordion>

<Tabs>
  <Tab title="Obtener miembro">
```bash
curl "https://{BASE_URL}/api/v1/app/project/{projectID}/member/{wsMemberId}" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}"
```

## Errores y casos límite

- **403**: no tienes permisos para administrar miembros.
- **404**: proyecto o miembro del espacio de trabajo no encontrado.
