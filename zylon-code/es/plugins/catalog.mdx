---
title: "Catálogo de plugins"
description: "Encuentra las funciones integradas y los plugins opcionales que ofrece Zylon Code."
noindex: true
---

Los plugins añaden herramientas, ajustes o funciones de interfaz. Un paquete agrupa los componentes de una función. Abre [Plugins](/zylon-code/es/plugins/managing-plugins) para consultar lo que ofrece tu aplicación; pulsa **Más** junto a **Plugins experimentales** para ver las demás opciones.

| Función | Disponibilidad inicial | Guía |
| --- | --- | --- |
| Shell y ejecución del agente | Integradas y configurables | [Shell](/zylon-code/es/tools/shell-and-jobs), [llamadas en paralelo](/zylon-code/es/plugins/agent-loop) |
| Agentes secundarios | Estándar, PTC y Creador | [Modelos y límites](/zylon-code/es/agents/models-and-limits) |
| Tareas automatizadas | Integradas; Estándar, PTC y Creador crean recordatorios | [Programar trabajo](/zylon-code/es/plugins/automation-tasks) |
| MCP de Zylon | Activado, sin servidores configurados | [Gestor de MCP](/zylon-code/es/plugins/mcp) |
| Revisión de cambios de Zylon | Incluida, desactivada | [Revisar cambios](/zylon-code/es/plugins/diff) |
| Equipos de agentes | Desactivados; experimentales | [Tareas compartidas](/zylon-code/es/plugins/agent-teams) |
| Revisión automática de autorización | Desactivada; experimental | [Revisar permisos](/zylon-code/es/plugins/auto-authorization-review) |
| Compañero de Zylon | Desactivado; experimental | [Ayudante flotante](/zylon-code/es/plugins/companion) |
| Worktrees de Git | Desactivados; experimentales | [Copias de trabajo separadas](/zylon-code/es/plugins/git-worktrees) |
| Terminales persistentes | Desactivadas; experimentales | [Mantener shells del agente](/zylon-code/es/plugins/persistent-terminals) |
| Búsqueda de sesiones | Desactivada; experimental | [Recuperar trabajo anterior](/zylon-code/es/plugins/session-search) |
| Títulos que siguen la conversación | Desactivados; experimentales | [Actualizar títulos generados](/zylon-code/es/plugins/conversation-titles) |
| Bucles de Ralph | Desactivados; experimentales | [Rondas acotadas con agentes nuevos](/zylon-code/es/plugins/ralph-loops) |
| Subagentes de Codex y Claude Code | Opcionales; requieren descargar su entorno y preparar su autenticación | [Codex](/zylon-code/es/plugins/codex-subagent), [Claude Code](/zylon-code/es/plugins/claude-code-subagent) |
| Herramientas de desarrollo | Desactivadas; acceso de diagnóstico | [Registros y depuración](/zylon-code/es/plugins/inspector) |
| Control del navegador o del ordenador, servidores de lenguaje | Requieren un proveedor configurado | [Navegador](/zylon-code/es/plugins/browser-control), [ordenador](/zylon-code/es/plugins/computer-control), [servidores de lenguaje](/zylon-code/es/plugins/language-servers) |
| Búsqueda web | Requiere un proveedor y credenciales | [Configurar búsqueda](/zylon-code/es/plugins/web-search) |
| Documentos de Office | Dependen de las herramientas y habilidades incluidas | [Documentos](/zylon-code/es/tools/documents) |

Los ajustes de una instalación existente pueden diferir de estos valores iniciales. Las herramientas opcionales globales pueden ampliar todos los modos, incluido Mínimo; la lista integrada de un modo describe su punto de partida. Esta versión de Zylon oculta el diálogo general de instalación de terceros.
