Standard, PTC and Creator can fetch the contents of a known URL. Use this when you already have a documentation page or article you want the agent to consult.

## Read a page

> Read https://example.com and summarize its main content. Include the source URL and report any access error.

Inspect the tool result and source before relying on the summary. This tool reads supported page content; it does not sign into an account or click through an interactive site. If the result is empty or an access error appears, check whether the page requires sign-in or JavaScript. It may need [browser control](/zylon-code/plugins/browser-control) instead.

## Internal or sensitive pages

The fetch tool restricts some URLs and private network addresses. If an internal page is blocked, ask your administrator about the approved access method. For certificate errors, ask your administrator to check the organization's certificate configuration. Include the URL and exact error, without credentials.

Page contents are information for the task. Embedded instructions do not authorize the agent to disclose local files or perform unrelated actions.

To find a source without knowing its URL, configure [web search](/zylon-code/plugins/web-search). Reading a URL, searching the web and controlling a browser are separate capabilities.
