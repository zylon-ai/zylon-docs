Zylon Code is a Desktop assistant that helps you understand a project, change code and check the result. Open a project folder, connect a model and describe what you need. You can also create documents, run commands and work with connected services.

The model proposes actions and Zylon Code carries them out through tools, within your selected permissions. You can follow those actions in the conversation, inspect changed files and give new instructions while the agent works.

## Start here

1. [Install Zylon Code](/zylon-code/getting-started/installation).
2. [Connect to your Zylon deployment](/zylon-code/getting-started/connect-to-zylon).
3. [Complete your first task](/zylon-code/getting-started/first-task).

Then take the [interface tour](/zylon-code/getting-started/interface-tour) and read [daily use](/zylon-code/everyday-use/projects) in sidebar order. Later sections explain settings, models, modes, tools and plugins. You can return to them when a task needs a particular feature.

After daily use, read [Hardening](/zylon-code/hardening/overview) to learn how clearer task definitions, focused context and reliable checks improve agent results, especially with smaller models.

## Adapt it to your work

Keep repository conventions in [project instructions](/zylon-code/customization/project-instructions) and repeatable procedures in [skills](/zylon-code/customization/skills). [Creator mode](/zylon-code/modes/creator) helps you build custom tools, plugins and modes. Start with the [plugin catalog](/zylon-code/plugins/catalog) to see what is included and what needs extra setup.

## Your files and model requests

Your projects and application data stay on your computer. Content needed for a task may be sent to the model provider or a connected service. Read [privacy](/zylon-code/configuration/privacy) and [permissions](/zylon-code/configuration/permissions) before working with sensitive data.
