Comprueba el estado actual antes de repetir un trabajo interrumpido. Una interfaz desconectada no significa que un comando se haya detenido, y cancelar una tarea no restaura los archivos.

## Recupera la conexión

Si aparece una desconexión, utiliza la opción de reintento junto a Ajustes. Si continúa, sal de la aplicación por completo y vuelve a abrirla. Conserva el error para soporte. Evita restablecer la carpeta de datos solo para reparar una conexión.

## Revisa el trabajo interrumpido

Consulta los archivos actuales, cambios de Git, procesos y último resultado de herramienta. Tras reiniciar un proveedor, puede ser necesario recuperar las pestañas externas o iniciar sesión de nuevo.

Explica al agente qué ha ocurrido:

> La tarea se ha detenido después de editar config.ts. Lee el archivo actual y consulta el último comando registrado. Explica lo que falta antes de repetir ediciones o instalar nada.

## Informa del problema

Incluye la versión de la aplicación, sistema operativo y arquitectura, modo, proveedor y modelo, plugin afectado, pasos para reproducirlo y error exacto. Quita credenciales y datos privados de registros, capturas y exportaciones antes de compartirlos.

Conserva los originales y comparte una copia sin información privada. Si la recuperación va a modificar datos guardados, haz primero una copia; [Datos y copias de seguridad](/zylon-code/es/configuration/data-and-backups) explica qué conservar.
