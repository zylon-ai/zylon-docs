Zylon Code is a desktop application that helps you work on your projects with AI. Ask it to explain code, fix a bug, write tests or prepare a document. It can read files, make changes and run commands in your project folder.

You describe the task in a conversation. The **agent** is the assistant that carries it out, using the model, tools and permissions you choose. While it works, you can inspect its actions, review changes and give it further instructions.

## Get started

1. [Download and install Zylon Code](/zylon-code/getting-started/installation).
2. Check the [license and access requirements](/zylon-code/getting-started/license-and-access).
3. [Connect to Zylon](/zylon-code/getting-started/connect-to-zylon).
4. [Complete your first task](/zylon-code/getting-started/first-task): turn meeting notes into a plan and review the result.

The [interface tour](/zylon-code/getting-started/interface-tour) shows where to find the main controls. Continue with [everyday use](/zylon-code/everyday-use/projects) to organize projects, manage conversations and review results.

## Get more from the agent

[Hardening](/zylon-code/hardening/overview) explains how to make agent work more reliable: define a clear task, provide useful context and check the outcome. These practices are especially useful with smaller models.

Use [project instructions](/zylon-code/customization/project-instructions) to explain how your team works, and [skills](/zylon-code/customization/skills) to save procedures you repeat. The [plugin catalog](/zylon-code/plugins/catalog) covers additional features and their setup. When you need your own tools or modes, start with [Creator mode](/zylon-code/modes/creator).

## Your files and data

Projects and conversations are stored on your computer. Working locally does not mean all processing happens there: messages, relevant file content and tool results may be sent to your model provider or a connected service. Read about [privacy](/zylon-code/configuration/privacy) and [permissions](/zylon-code/configuration/permissions) before working with sensitive data.
