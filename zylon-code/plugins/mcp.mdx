MCP lets the agent use another service’s tools, for example to look up project issues or read shared documentation. The MCP server provides those tools, and Zylon Code connects to it. Zylon MCP Manager is enabled in new profiles with an empty server list. Existing profiles retain their selection; enable the supplied Zylon MCP plugin if the **MCPs** tab is absent.

## Add an HTTP server

1. Open **Plugins → MCPs → Add server**.
2. Name the server and choose **Server URL (HTTP)**.
3. Paste the provider's exact MCP endpoint.
4. Choose no authentication, OAuth, OAuth-or-none, or a bearer token. Enter a bearer token without the word `Bearer`.
5. Choose **Connect and create**. Complete OAuth in the sign-in window if requested.
6. Verify the saved card and discovered tools.

The server is saved only after Zylon Code connects and retrieves its available tools. Failed or cancelled creation leaves no saved server. OAuth servers must support public-client registration and PKCE; manually configured OAuth clients are outside this version.

## Add a local command

Choose **Local command (STDIO)**. Enter the executable available on your computer, then one argument per field. For `npx`, the provider may require `-y` followed by its package name; use that provider's actual instructions. These are values for the application’s form; you do not need to open a terminal. If the required program is unavailable, ask your administrator to prepare it or provide an HTTP server. Do not paste a shell command line into the executable field.

| Field | Use |
| --- | --- |
| Command | Local executable, such as the provider's `npx` or `uvx` launcher. |
| Arguments | Separate ordered arguments. |
| Working directory | Optional process startup folder; not an access grant. |
| Environment variables | Provider-required names and protected values. |
| HTTP headers | Protected fields required by the provider for an HTTP server. |

Use protected fields for credentials, not command arguments or URLs. Blank saved values preserve existing secrets; removing a row removes its value.

## Use and maintain

Type `@` in a project chat and choose an enabled MCP. The reference identifies its tools but does not bypass permissions or mode restrictions. If the server was disabled, renamed or removed after selection, update the mention before sending.

For an issue-tracking server that offers search, you could ask: “Find open issues about login errors in this project and summarize their current status. Do not change any issues.”

Use **Test connection** to check the connection and available tools without running a tool or calling the model. **Last test** shows the previous result, not a live status. **Sign in** lets you restore OAuth access to an existing server. Use the card menu to edit or delete it.

Disabling the plugin retains configuration and credentials; deleting a server removes both. Servers defined in an external profile are read-only in the manager. **Export configuration** saves settings without secrets or test results; this version does not offer configuration import. Re-enter credentials when moving the configuration to another installation.
