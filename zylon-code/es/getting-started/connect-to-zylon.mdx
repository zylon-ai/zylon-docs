Ten a mano el **dominio de Zylon** de tu organización, por ejemplo `https://zylon.example`. Su [licencia debe incluir Zylon Code](/zylon-code/es/getting-started/license-and-access). También necesitarás una **clave de API de un gateway** para acceder a los modelos de Zylon; el paso 2 explica cómo crearla.

## 1. Conecta el dominio de Zylon

Abre Zylon Code, introduce el **Dominio de Zylon** en la pantalla de bienvenida y pulsa **Conectar**. Utiliza la dirección que te facilite el administrador, con `http://` o `https://` y el puerto si hace falta.

Introduce solo la dirección base. Por ejemplo, si Backoffice muestra `https://zylon.example/api/gpt`, escribe `https://zylon.example`. No añadas credenciales ni parámetros.

Cuando se haya comprobado la licencia, podrás acceder a la aplicación. Para cambiar el dominio más adelante, abre **Ajustes → General → Conexión con Zylon**. Si no puedes conectar, consulta [Licencia y acceso](/zylon-code/es/getting-started/license-and-access).

Si tu organización utiliza un certificado privado, puede aparecer una confirmación con el servidor, la huella, el emisor y las fechas de validez. Contrasta esos datos con el administrador antes de pulsar **Confiar y conectar**.

## 2. Crea una clave de API del gateway

Un gateway da acceso a los modelos que ofrece tu organización. Para crear una clave, tu cuenta necesita acceso de Desarrollador y acceso a ese gateway. Si te falta alguno de los dos, pídeselo al administrador.

1. En Backoffice, abre **Consola de desarrollo** y selecciona el gateway.
2. Abre **Claves de API** y pulsa **Nueva clave de API**.
3. Escribe un nombre, elige **Lectura y escritura** y establece una fecha de caducidad.
4. Crea la clave y cópiala enseguida. Su valor solo se muestra una vez.

Cuando hay descargas disponibles, este diálogo también incluye las instrucciones para instalar Zylon Code. Si todavía no tienes la aplicación, descárgala desde ahí y sigue [Descarga e instalación](/zylon-code/es/getting-started/installation).

Utiliza una clave del **gateway**, en lugar de un token que solo dé acceso a Workspace.

## 3. Guarda la clave y elige un modelo

Abre **Ajustes → Modelos**, busca la conexión de Zylon y pega la clave en **Token de desarrollador**. Pulsa **Guardar conexión**. La **URL de los modelos** se rellena automáticamente a partir del dominio que has indicado; no necesitas editarla.

Una vez guardada la conexión, abre el selector de modelos del cuadro de mensajes y elige uno disponible. Si la lista está vacía o no puedes guardar la conexión, consulta [Acceso a modelos](/zylon-code/es/troubleshooting/setup-and-models#acceso-a-modelos).

Guarda la clave en **Token de desarrollador**; no la pegues en una conversación.

## 4. Prueba una tarea sencilla

[Selecciona una carpeta de proyecto](/zylon-code/es/everyday-use/projects) y abre una conversación con **Nueva sesión**. Elige los permisos **Solo lectura** en el cuadro de mensajes y envía:

> Enumera los archivos de la carpeta principal del proyecto. Lee un archivo de texto pequeño y resume para qué sirve. No modifiques archivos ni instales nada.

Comprueba que la respuesta describe un archivo de la carpeta que has elegido. Despliega las tarjetas de herramientas para ver qué ha leído el agente. Si aparece un error, consulta [problemas de conexión](/zylon-code/es/troubleshooting/setup-and-models).

Continúa con [Tu primera tarea](/zylon-code/es/getting-started/first-task) para hacer y revisar un cambio pequeño.
