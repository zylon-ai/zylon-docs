Abre **Ajustes → General → Editar atajos**, o pulsa **Mod+/**, para ver los atajos de tu instalación. **Mod** significa Comando en macOS y Control en Windows. Puedes buscar por acción o combinación de teclas.

## Atajos predeterminados

| Acción | Atajo en Desktop |
| --- | --- |
| Nueva conversación | Mod+N |
| Buscar conversaciones | Mod+K |
| Añadir carpeta de proyecto | Mod+O |
| Renombrar conversación | Mod+Alt+G |
| Bifurcar conversación | Mod+Alt+F |
| Archivar conversación | Mod+Mayús+A |
| Mostrar u ocultar la barra izquierda | Mod+B |
| Mostrar u ocultar la barra derecha | Mod+Alt+B |
| Dividir el panel activo | Mod+Barra inversa |
| Alternar pantalla completa del panel | Mod+Alt+Intro |
| Cerrar página o diálogo superior | Mod+W |
| Abrir la referencia de atajos | Mod+/ |
| Abrir Cambios pendientes, con el plugin de revisión activado | Ctrl+D |

Consulta la referencia de la aplicación si has personalizado un atajo o un plugin añade una acción.

## Mensajes y menús

Escribe `/` para comandos y habilidades, y `@` para referencias. Arriba y Abajo recorren las sugerencias; Intro o Tab aceptan una opción. Escape cierra las ventanas emergentes compatibles y el visor de imágenes.

Mientras trabaja el agente, Intro sigue tu preferencia de envío. Comprueba si la acción activa pone el mensaje en cola o dirige la tarea. Detener es una acción independiente.

## Personaliza un atajo

Selecciona una acción, pulsa la nueva combinación y suelta las teclas para guardarla. **Eliminar** quita el atajo; **Restablecer valor predeterminado** elimina tu modificación. No se permiten conflictos y las acciones fijas de entrada son de solo lectura.

Si no responde, comprueba qué editor, campo o diálogo tiene el foco. Prueba primero el botón visible antes de cambiar su combinación.
