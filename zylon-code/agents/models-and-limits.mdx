Open **Plugins → Built-in plugin settings → Subagent** to set delegation limits and the models agents may choose. External agent applications need separate setup.

| Setting | Meaning |
| --- | --- |
| Maximum recursion depth | Limits nested delegation for tools that inherit this setting; a tool with its own depth setting takes precedence. |
| Parallelism limit | Limits live or starting subagents at every level beneath one main agent, including external runs; the main agent itself is excluded. |
| Model selection | Allows the agent to choose among explicitly selected routes. |
| Allowed routes | The specific provider and model each agent may use. |

## Save a configuration

Enter valid whole-number limits, enable model selection only if needed and select at least one route. Save. Leaving the page discards unsaved edits. Saved-but-unavailable routes remain visible and removable; they do not become usable simply because they are listed.

A conflict means the configuration changed after the draft was loaded. Reload the affected draft and review the current settings instead of overwriting them blindly. The two settings sections can report independent save failures.

Model selection and the allowed provider/model combinations are recorded when a new main conversation starts. Later settings changes do not rewrite that conversation’s recorded policy or the policy inherited by its children. Start a new conversation to use newly allowed models.

Depth changes apply at the next delegation attempt for tools that inherit this setting. The parallelism limit is checked when starting or resuming an agent: lowering it leaves existing agents running and blocks additional starts until capacity is available.

At capacity, a new start is rejected rather than queued. Wait for an existing child to finish or continue with one already running. Waiting parents and agents still cleaning up can retain a slot. The limit bounds active work, not cumulative token use.

## Choose practical limits

More parallel agents increase simultaneous model calls and machine load. Use independent scopes and small limits first. Limit changes do not make shared files safe for concurrent editing. Tell the parent which model and expected outcome to use when the task requires consistency.

For separately installed Codex or Claude Code applications, use [external agents](/zylon-code/advanced/external-agents).
