Open **Settings → General → Edit shortcuts**, or press **Mod+/**, to see the shortcuts active in your installation. **Mod** means Command on macOS and Control on Windows. Search by action or key combination.

## Default application shortcuts

| Action | Desktop shortcut |
| --- | --- |
| Open settings | Mod+, |
| Increase / decrease text, code and terminal font sizes | Mod+= / Mod+- |
| New conversation | Mod+N |
| Search conversations | Mod+K |
| Add project folder | Mod+O |
| Rename conversation | Mod+Alt+G |
| Fork conversation | Mod+Alt+F |
| Archive conversation | Mod+Shift+A |
| Toggle left sidebar | Mod+B |
| Toggle right sidebar | Mod+Alt+B |
| Split active pane | Mod+Backslash |
| Toggle pane fullscreen | Mod+Alt+Enter |
| Close page or top dialog | Mod+W |
| Open shortcut reference | Mod+/ |
| Open Pending changes, with Diff Review enabled | Ctrl+D |

The installed reference is authoritative when you have customized a binding or an optional plugin adds an action.

Desktop reserves the font-size combinations, including Mod+Shift+= for `+`. If an older custom binding conflicts, record another combination.

## Composer and menus

Type `/` for commands and skills, and `@` for references. Use Up/Down to move through suggestions and Enter/Tab to accept an option. Escape closes supported popups and the image viewer.

While the agent works, Enter follows your send preference. Check whether the active action queues a message or steers the task. Stop is a separate action.

## Customize a binding

Select an application action, press the new combination and release the keys to save it. **Remove** clears the binding; **Restore Default** removes your override. Conflicts are rejected and fixed input actions are read-only.

If a shortcut does nothing, check which editor, input or dialog has focus. Try the visible action before changing its binding.
