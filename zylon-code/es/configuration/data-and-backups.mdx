Zylon Code guarda normalmente los datos de la aplicación en `~/.zylon-code`; `~` representa tu carpeta de usuario. Los archivos del proyecto permanecen en las carpetas que seleccionaste. Si tu organización ha configurado otra ubicación, utiliza esa para las copias.

| Datos | Qué conservar |
| --- | --- |
| Código y entregables | Las carpetas de proyecto, mediante Git o tus copias habituales. |
| Conversaciones y adjuntos | La carpeta de datos de la aplicación y su almacenamiento de sesiones. |
| Ajustes de modelos y plugins | La configuración guardada en la carpeta de datos. |
| Credenciales | Su almacenamiento separado; protege las copias que las incluyan. |

## Exporta una conversación

Selecciona **Exportar** o `/export` en un chat. Completa el diálogo de descarga y comprueba que el archivo se ha guardado. Revísalo antes de compartirlo: puede contener mensajes, rutas y resultados de herramientas. La exportación recoge la conversación, no hace una copia de los archivos del proyecto.

## Haz una copia o traslada tus datos

1. Sal de Zylon Code por completo.
2. Copia su carpeta de datos y guarda por separado las carpetas de proyecto.
3. Conserva los originales hasta comprobar que puedes abrir las conversaciones, adjuntos y ajustes restaurados.

Sigue las instrucciones de la actualización cuando sea necesaria una migración. Evita modificar a mano el formato de las sesiones guardadas. Si no aparecen tus conversaciones, comprueba primero la ubicación de los datos antes de borrar o restablecer nada. Consulta [Recuperación](/zylon-code/es/troubleshooting/recovery).
