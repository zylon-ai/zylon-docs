Utiliza **Abrir en** en la cabecera de la conversación para abrir el proyecto en una aplicación compatible instalada en tu ordenador. Así puedes revisar o continuar el trabajo en tu editor habitual.

Si editas un archivo mientras trabaja el agente, pídele que vuelva a leer su contenido antes de cambiarlo. Zylon Code y el editor pueden modificar los mismos archivos.

## Integraciones ACP

Agent Client Protocol (ACP) conecta un entorno de agente con un editor o cliente compatible. Es una integración aparte, no un asistente de conexión incluido en Desktop. Tener un editor compatible no configura por sí solo el gateway de modelos de Zylon.

El responsable de la integración debe preparar el entorno, la conexión del modelo y los permisos para la versión instalada. Comprueba una tarea de lectura, una autorización y una cancelación antes de utilizarla para modificar archivos.

Para delegar desde Zylon Code en un agente ACP externo, consulta [Agentes externos](/zylon-code/es/advanced/external-agents). [Paneles y aplicaciones locales](/zylon-code/es/everyday-use/panels) explica las opciones habituales para abrir el proyecto.
