Un plugin personalizado puede añadir una herramienta, una página de ajustes o una función lateral. Utiliza una [habilidad](/zylon-code/es/customization/skills) para guardar las instrucciones de una tarea habitual; elige un plugin cuando necesites un comportamiento o una interfaz nuevos.

## Describe una función pequeña

> Crea un plugin Lista del proyecto. Guarda sus tareas, muéstralas en una página lateral y permite al agente listar, añadir y completar elementos. Mantén las autorizaciones en los controles del usuario. Incluye etiquetas en español e inglés, pasos de instalación y una forma de comprobarlo.

Explica qué datos deben conservarse al reiniciar, qué muestra la interfaz y qué puede hacer el agente. Indica qué operaciones deben quedar bajo tu control.

## Crea e instala

Inicia una conversación en [Creador](/zylon-code/es/modes/creator). Pídele que consulte las API instaladas, cree el plugin y lo prepare como paquete local. Creador se encarga de la instalación local; la página Plugins permite gestionar las funciones que ofrece tu aplicación. Revisa el código generado, las dependencias y los scripts antes de autorizar la instalación. Descargar un paquete o un entorno de ejecución puede requerir Internet o un registro interno. Pide al agente que confirme dónde ha guardado el plugin, si se ha activado y cómo desactivarlo si falla.

Prueba tanto la interfaz como las herramientas del agente. Comprueba un error relevante y qué ocurre al desactivarlo y reactivarlo. Si cambia las herramientas de un modo, puede hacer falta una conversación nueva.

## Conserva el plugin y comprueba su compatibilidad

Guarda el código, la configuración y la versión de la aplicación compatible. Zylon no mantiene ni traduce automáticamente los plugins generados o de terceros. Comprueba la compatibilidad antes de actualizar la aplicación y conserva instrucciones claras para retirar la función.
