External agents delegate work to a separate product runtime. Choosing that vendor's model in Models is a different operation: model access alone does not enable its coding agent.

| Bridge | Setup | Result |
| --- | --- | --- |
| [Codex subagent](/zylon-code/plugins/codex-subagent) | Enable its offered plugin; prepare native Codex authentication and settings | One fresh task; final answer or safe error returned to the parent. |
| [Claude Code subagent](/zylon-code/plugins/claude-code-subagent) | Enable its offered plugin; prepare native Claude authentication and settings | One fresh task; final answer or safe error returned to the parent. |
| ACP or another configured runtime | Administrator-provided executable, connection and model access | Provider-specific one-shot delegation. |

## Prepare access deliberately

Codex and Claude Code are available in **Plugins → Experimental plugins → More**. Enabling can download a compatible packaged runtime. Neither falls back to an executable found on your computer. Authentication and model choices remain native to that product; a Zylon token does not sign into it. Native permission policies are configured separately from the parent conversation.

Ask your administrator to prepare ACP or another integration that is not offered as a plugin. Do not infer support from an executable's presence alone.

## Verify one bounded task

Start with a read-only task containing all required paths, facts and restrictions. The external agent does not inherit the parent conversation. Check its final answer, cancellation and reported failures. It shares the current project directory unless another is explicitly selected, so review files separately when edits were allowed.

These runs do not accept follow-up messages or resume. The parent receives a completion result rather than a local conversation containing all native tool traffic. For continuing back-and-forth work, use Zylon's [local subagents](/zylon-code/agents/delegation). Both local and external activations count toward the [parallelism limit](/zylon-code/agents/models-and-limits).
