The left sidebar contains your projects and conversations. The center shows the conversation and the message box, also called the **composer**. The right panels let you open files, review outputs and use a terminal or browser.

| Area | What you can do |
| --- | --- |
| Projects and chats | Select a project, start a chat, search, pin, rename, fork or archive. |
| Composer | Write a request, attach files and choose model, mode and permissions. |
| Model picker | Choose which model will handle the next request. |
| Mode picker | Choose the agent's capabilities for a new task. |
| Permission picker | Set access and review approval requests. |
| Tool cards | See what the agent requested, what ran and what it returned. |
| Right panels | Browse files, inspect deliverables and run your own terminal commands. |
| Plugins | Enable features and configure integrations. |
| Settings | Change language, appearance, model connections and defaults. |

The Zylon domain and license are managed in **Settings → General**; its developer token is in **Settings → Models**. **Developer view** reveals advanced configuration views and additional programming modes.

## Use the composer

Click **+** or type `/` to open attachments, commands and available skills. Type `@` to select files, folders or enabled MCP servers. The options depend on your selected mode and plugins.

## Follow a task

Expand a tool card when you want to see an action's arguments, result or error. The work-detail preference changes how much process detail is shown. Questions and approvals appear with controls for your response.

Continue with [Projects](/zylon-code/everyday-use/projects), then follow the daily-use pages in order. [Keyboard shortcuts](/zylon-code/reference/keyboard-shortcuts) provides a reference when you need it.
