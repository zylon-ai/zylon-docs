Inspector es una función experimental de diagnóstico para desarrolladores y personal de soporte. Permite inspeccionar el entorno local y la interfaz con Chrome DevTools. No hace falta para las tareas habituales.

## Utilízalo con soporte

Empieza por [Recuperación e informes de soporte](/zylon-code/es/troubleshooting/recovery). Si soporte te pide utilizar Inspector, sigue las instrucciones de preparación y conexión de tu versión concreta. Recoge el error y la información de diagnóstico necesaria para ese problema.

<Warning>
Un depurador puede ejecutar código y mostrar credenciales, mensajes o contenido privado de archivos. Mantén el acceso local y revisa las capturas antes de compartirlas.
</Warning>

## Termina la investigación

Cierra el depurador y desactiva o retira la función según las instrucciones. Comprueba después que la aplicación se inicia con normalidad. Conserva los registros originales y comparte una copia sin credenciales ni datos privados.
