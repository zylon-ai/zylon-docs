---
title: "Visión general de Backoffice API"
description: "API de Backoffice para operaciones y tareas a nivel de plataforma."
---

La Backoffice API ofrece endpoints a nivel de plataforma para operadores autorizados y procesos de automatización. Úsala para tareas operativas que quedan fuera de la Workspace API, como recuperar registros de Zylon para investigar incidencias o exportarlos.

## URL base

Los endpoints de Backoffice se sirven desde la raíz de la plataforma:

```http
https://{BASE_URL}
```

A diferencia de la Workspace API, estos endpoints no usan el prefijo de workspace `/api/v1/app`.

## Autenticación y permisos

Las solicitudes requieren un token de cuenta o una sesión de cuenta con, al menos, el rol `operator`.

```bash
-H "Authorization: Bearer {API_TOKEN}"
```

<Note>
Los tokens exclusivos de Workspace no son suficientes para los endpoints de Backoffice.
</Note>

Consulta [Gestión de tokens](/es/v1.57/developer-manual/get-started/token-management) para elegir el flujo de autenticación adecuado.
