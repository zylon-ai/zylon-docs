Equipos de agentes permite que varios agentes se coordinen mediante mensajes y un tablero de tareas compartido. Es una función experimental incluida, pero desactivada de serie. Actívala en **Plugins → Oficiales → Equipos de agentes** e inicia una tarea nueva.

## Asigna trabajo al equipo

> Utiliza Equipos de agentes para revisar este cambio. Asigna las pruebas de API a un miembro y las de interfaz a otro. Mantén ambas revisiones en solo lectura, registra sus tareas y reúne los hallazgos cuando terminen.

El agente responsable puede crear miembros, enviar mensajes y asignar tareas. Abre sus conversaciones para consultar el trabajo. Indica quién se encarga de cada tarea y qué debe entregar para darla por terminada.

## Coordina las ediciones

Los miembros comparten los archivos del proyecto. La función no crea copias separadas ni bloquea archivos automáticamente. Asigna archivos distintos a cada agente o pide que revisen mientras uno aplica los cambios conjuntos.

Más miembros generan más peticiones al modelo y consumen más recursos. Empieza con un equipo pequeño y tareas independientes.

## Comprueba y desactiva

Revisa los miembros, los estados de las tareas y el informe final. Decide qué hacer con el trabajo fallido o cancelado. Desactiva el paquete para volver a las herramientas anteriores y compruébalo en una tarea nueva. Los cambios en archivos se mantienen.

Utiliza [delegación](/zylon-code/es/agents/delegation) para una revisión independiente más sencilla o [flujos de trabajo](/zylon-code/es/tools/workflows) para una secuencia coordinada mediante un script.
