Open **Settings** at the bottom of the sidebar. You can choose English or Spanish, light or dark appearance, and defaults for future conversations.

| Area | What you configure |
| --- | --- |
| General | Language, appearance and conversation defaults. |
| Models | Credentials, connection URLs and available models. |
| Built-in plugins | A read-only list of the application's components. |
| Plugins in the sidebar | Feature switches and settings such as Shell and agent limits. |

The **Coding Tools** switch changes the settings and mode-selection experience. To control file or command access, use [permissions](/zylon-code/configuration/permissions).

## Defaults and current conversations

A new mode default applies to new tasks. Changing the model in a conversation applies to its next model request. The permission picker controls the current conversation. Check the corresponding guide before changing a default while work is running.

## Save your changes

Shell, Agent execution and Subagent forms keep a draft until you select **Save**. Leaving those pages without saving discards the draft. Use the reset control to return a field to its default and follow any restart notice.

**Open configuration file**, when available, opens the application's local configuration. Prefer the normal forms unless you need a setting they do not expose; [Profiles and YAML](/zylon-code/advanced/profiles-and-yaml) explains that advanced option.
