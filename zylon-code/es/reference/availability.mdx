Las funciones dependen de la versión de la aplicación, el modo elegido y los plugins activados. Consulta esta tabla si no encuentras un control esperado.

| Función | Disponibilidad |
| --- | --- |
| Estándar | Predeterminado para tareas nuevas. |
| PTC, Mínimo y Creador | Modos incluidos con herramientas distintas. |
| Instrucciones, habilidades, planificación, objetivos y compactación | Estándar, PTC y Creador; no el modo Mínimo integrado. |
| Flujos de trabajo | Estándar y Creador; desactivados en PTC. |
| Gestor de MCPs | Activado en instalaciones nuevas, sin servidores configurados. |
| Revisión de cambios, automatización, equipos, revisión automática y Companion | Incluidos, pero desactivados al empezar; algunos son experimentales. |
| Lectura de URL | Incluida en Estándar, PTC y Creador. |
| Búsqueda web | Necesita credenciales del proveedor y configuración del modo. |
| Panel de navegador | Incluido en Desktop. |
| Automatización del navegador y ordenador, LSP y agentes externos | Necesitan configuración de la integración. |
| Inspector | Diagnóstico opcional para soporte o desarrollo. |

Una instalación existente conserva sus ajustes. Algunas funciones descritas necesitan preparación adicional antes de poder utilizarlas en tu versión.

## Sistemas operativos y distribución

Utiliza la aplicación compilada y las instrucciones que te facilite tu contacto de Zylon. Los objetivos de empaquetado actuales incluyen macOS ARM64/x64 y Windows x64; la información de instalación indicará qué versiones están disponibles. Este manual no ofrece un instalador Desktop para Linux.

Una conexión interna de modelos no garantiza por sí sola el funcionamiento sin internet. Sigue la [guía de red](/zylon-code/es/advanced/network-and-offline) para ese entorno. Los plugins propios o de terceros pueden tener requisitos de plataforma e idioma diferentes.
