Las funciones dependen de la versión instalada, los ajustes guardados, el modo y los plugins activos. Para ejecutar tareas necesitas un dominio con licencia de Zylon, aunque utilices otro proveedor de modelos.

| Función | Disponibilidad |
| --- | --- |
| Estándar y Creador | Incluidos; Estándar es el predeterminado inicial. |
| PTC y Mínimo | Incluidos; activa General → Vista de desarrollo para elegirlos en tareas nuevas. |
| Instrucciones del proyecto, habilidades, planificación, objetivos y delegación local | Estándar, PTC y Creador; no se incluyen en Mínimo. |
| Compactación y lectura de imágenes | En los cuatro modos integrados; las imágenes también requieren un modelo compatible. |
| Flujos de trabajo | Estándar y Creador; desactivados en PTC. |
| Directorio de trabajo | Herramienta integrada para consultar o cambiar el directorio de una conversación; los procesos existentes conservan el suyo. |
| Tareas automatizadas | Integradas; Estándar, PTC y Creador tienen herramientas de recordatorios, pero los agentes delegados no. |
| Gestor de MCP | Activado en instalaciones nuevas, sin servidores configurados. |
| Revisión de cambios, equipos, revisión automática y Companion | Incluidos, pero desactivados inicialmente; algunos son experimentales. |
| Worktrees, terminales persistentes, búsqueda de sesiones, títulos y bucles de Ralph | Opcionales y desactivados; están en Plugins → Plugins experimentales → Más. |
| Subagentes de Codex y Claude Code | Opcionales; necesitan descargar un entorno compatible y preparar su autenticación nativa. |
| Lectura de URL | Incluida en Estándar, PTC y Creador. |
| Búsqueda web | Requiere un proveedor aprobado, credenciales y configuración del modo. |
| Panel de navegador | Incluido en Desktop. |
| Automatización del navegador y del ordenador, servidores de lenguaje | Requieren preparar el proveedor y el sistema. |
| Herramientas de desarrollo | Depuración y diagnósticos sin ocultación de datos; utilízalas con soporte. |

Las herramientas globales opcionales pueden ampliar cualquier modo, incluido Mínimo. Las instalaciones existentes conservan sus ajustes y pueden diferir de estos valores iniciales. Zylon oculta el instalador general de terceros y algunas funciones del proyecto original; consulta su [catálogo de plugins](/zylon-code/es/plugins/catalog).

## Sistemas operativos y distribución

Utiliza la aplicación Desktop compilada y las indicaciones de tu plataforma en [Instalación](/zylon-code/es/getting-started/installation). Que exista un paquete de código o que una función del proyecto original admita una plataforma no confirma que esté disponible en el binario que recibes. Las integraciones opcionales pueden tener requisitos adicionales.

Una conexión interna de modelos no garantiza el funcionamiento sin internet. La [guía de red](/zylon-code/es/advanced/network-and-offline) explica la licencia, los certificados y las dependencias externas.
