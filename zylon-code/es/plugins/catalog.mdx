Los plugins añaden herramientas, ajustes o funciones de interfaz a Zylon Code. Algunos ya forman parte de la aplicación; otros están incluidos, pero empiezan desactivados. Un **paquete** o *bundle* agrupa los componentes que necesita una función.

| Función | Disponibilidad inicial | Guía |
| --- | --- | --- |
| Shell | Incluida | [Comandos y límites](/zylon-code/es/tools/shell-and-jobs) |
| Ejecución del agente | Incluida | [Herramientas en paralelo](/zylon-code/es/plugins/agent-loop) |
| Agentes secundarios | Estándar, PTC y Creador | [Modelos y límites](/zylon-code/es/agents/models-and-limits) |
| MCPs de Zylon | Activados, sin servidores configurados | [Gestor de MCPs](/zylon-code/es/plugins/mcp) |
| Revisión de cambios de Zylon | Incluida, desactivada | [Revisar cambios y enviar comentarios](/zylon-code/es/plugins/diff) |
| Tareas automatizadas | Incluidas, desactivadas | [Programar trabajo](/zylon-code/es/plugins/automation-tasks) |
| Equipos de agentes | Incluidos, desactivados; experimental | [Tareas compartidas](/zylon-code/es/plugins/agent-teams) |
| Revisión automática de autorización | Incluida, desactivada; experimental | [Revisar permisos](/zylon-code/es/plugins/auto-authorization-review) |
| Zylon Companion | Incluido, desactivado; experimental | [Compañero flotante](/zylon-code/es/plugins/companion) |
| Control del navegador | Necesita un proveedor configurado | [Automatización del navegador](/zylon-code/es/plugins/browser-control) |
| Control del ordenador | Necesita un proveedor y permisos del sistema | [Interacción con el escritorio](/zylon-code/es/plugins/computer-control) |
| Búsqueda web | Necesita un proveedor y credenciales | [Exa y Perplexity](/zylon-code/es/plugins/web-search) |
| Servidores de lenguaje | Necesita un servidor configurado | [Navegación por símbolos](/zylon-code/es/plugins/language-servers) |
| Inspector | Función opcional de soporte o desarrollo | [Diagnóstico](/zylon-code/es/plugins/inspector) |
| Office | Depende de las herramientas y habilidades incluidas | [Documentos](/zylon-code/es/tools/documents) |

Una instalación existente conserva sus ajustes guardados, aunque cambien los valores de una instalación nueva. Abre **Plugins** para ver qué funciones ofrece tu versión. El inventario integrado también muestra componentes internos; no necesitas instalarlos uno por uno.

Continúa con [Gestionar plugins](/zylon-code/es/plugins/managing-plugins).
