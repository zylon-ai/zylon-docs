title: "Omnisearch"
description: "Configura los idiomas y la longitud de consulta de Omnisearch."
---

Omnisearch combina búsqueda por palabras clave y búsqueda semántica en proyectos, chats, artefactos y contenido de artefactos.

## Configuración

```yaml
languages:
  keywordSearch: ["en", "es", "de"]

omnisearch:
  maxQueryCharacters: 80
```

| Clave | Valor predeterminado | Valores | Descripción |
| --- | --- | --- | --- |
| `languages.keywordSearch` | `["en"]` | Lista de códigos de idioma compatibles | Selecciona los diccionarios de búsqueda de texto de PostgreSQL usados para indexar y ordenar las coincidencias por palabras clave. |
| `omnisearch.maxQueryCharacters` | `80` | Entero mayor o igual que `3` | Establece la longitud máxima admitida para una consulta después de eliminar los espacios iniciales y finales. |

Después de cambiar la configuración, ejecuta `sudo zylon-cli sync`.

## Cómo funciona la configuración de idiomas

`languages.keywordSearch` solo afecta a la búsqueda por palabras clave. Para cada idioma configurado, Zylon crea y consulta un índice de texto completo de PostgreSQL específico del idioma. Configura todos los idiomas usados en tus proyectos, chats y documentos para que la lematización y el ranking por palabras clave utilicen los diccionarios adecuados.

La búsqueda semántica en el contenido de artefactos sigue una ruta distinta: envía la consulta a PrivateGPT y usa el modelo de embeddings habilitado. Por tanto, la cobertura semántica de idiomas depende de ese modelo de embeddings, no de `languages.keywordSearch` ni del modelo de chat multimodal.

Para la recuperación semántica multilingüe, habilita la capacidad multilingüe en el preset de IA seleccionado:

```yaml
ai:
  preset: "baseline-48g,capabilities.multilingual"
```

Esta capacidad selecciona el modelo de embeddings `multilingual-e5-large`. Consulta [capacidades de los presets de IA](/es/operator-manual/ai-presets/configuration).

<Warning>
  No dejes `languages.keywordSearch` vacío. Omnisearch rechaza las solicitudes cuando no hay ningún idioma de búsqueda por palabras clave configurado. Los códigos de idioma no compatibles también provocan un error.
</Warning>

### Idiomas compatibles con la búsqueda por palabras clave

| Idioma | Código | Idioma | Código |
| --- | --- | --- | --- |
| Árabe | `ar` | Armenio | `hy` |
| Vasco | `eu` | Catalán | `ca` |
| Danés | `da` | Neerlandés | `nl` |
| Inglés | `en` | Finlandés | `fi` |
| Francés | `fr` | Alemán | `de` |
| Griego | `el` | Hindi | `hi` |
| Húngaro | `hu` | Indonesio | `id` |
| Irlandés | `ga` | Italiano | `it` |
| Lituano | `lt` | Nepalí | `ne` |
| Noruego | `no` | Portugués | `pt` |
| Rumano | `ro` | Ruso | `ru` |
| Serbio | `sr` | Español | `es` |
| Sueco | `sv` | Tamil | `ta` |
| Turco | `tr` | Yidis | `yi` |

Los códigos de idioma no distinguen mayúsculas de minúsculas. Las entradas duplicadas se eliminan.

## Comportamiento de la longitud de consulta

Las consultas deben contener al menos tres caracteres. `omnisearch.maxQueryCharacters` cambia el límite superior aplicado por el backend, la API de Workspace y el campo de búsqueda de Workspace.

<Note>
  Mantén el valor predeterminado de `80` salvo que los usuarios necesiten consultas más largas. El mismo límite configurado se aplica a las solicitudes de API y al campo de búsqueda de Workspace.
</Note>
