Inspector is an optional experimental diagnostic feature for developers and support staff. It lets them inspect the application's local runtime and interface through Chrome DevTools. It is not needed for normal tasks.

## Use it with support

Begin with [Recovery and support reports](/zylon-code/troubleshooting/recovery). If support asks you to use Inspector, follow the setup and connection instructions for your exact build. Capture the specific error and the smallest relevant diagnostic information.

<Warning>
A debugger can execute code and expose credentials, prompts or private file content. Keep access local and review captures before sharing them.
</Warning>

## Finish the investigation

Close the debugger and disable or remove the feature as instructed. Confirm that the application starts normally afterward. Keep the original diagnostic records and share a copy with credentials and private data removed.
