Plugins add tools, settings or interface features. A bundle groups the components needed by one feature. Open [Plugins](/zylon-code/plugins/managing-plugins) to see what your application offers; use **More** beside **Experimental plugins** for the additional optional entries.

| Feature | Initial availability | Guide |
| --- | --- | --- |
| Shell and Agent execution | Built in; configurable | [Shell](/zylon-code/tools/shell-and-jobs), [parallel tool calls](/zylon-code/plugins/agent-loop) |
| Subagents | Standard, PTC and Creator | [Models and limits](/zylon-code/agents/models-and-limits) |
| Automation tasks | Built in; Standard, PTC and Creator can create reminders | [Schedule work](/zylon-code/plugins/automation-tasks) |
| Zylon MCPs | Enabled, with no servers configured | [MCP Manager](/zylon-code/plugins/mcp) |
| Zylon Diff Review | Included, disabled | [Review changes](/zylon-code/plugins/diff) |
| Agent Teams | Disabled; experimental | [Shared team tasks](/zylon-code/plugins/agent-teams) |
| Auto Authorization Review | Disabled; experimental | [Review permissions](/zylon-code/plugins/auto-authorization-review) |
| Zylon Companion | Disabled; experimental | [Floating helper](/zylon-code/plugins/companion) |
| Git Worktrees | Disabled; experimental | [Separate Git checkouts](/zylon-code/plugins/git-worktrees) |
| Persistent terminals | Disabled; experimental | [Keep agent shells open](/zylon-code/plugins/persistent-terminals) |
| Session search | Disabled; experimental | [Retrieve earlier work](/zylon-code/plugins/session-search) |
| Conversation-following titles | Disabled; experimental | [Update generated titles](/zylon-code/plugins/conversation-titles) |
| Ralph loops | Disabled; experimental | [Bounded fresh-agent rounds](/zylon-code/plugins/ralph-loops) |
| Codex and Claude Code subagents | Optional; runtime download and native authentication required | [Codex](/zylon-code/plugins/codex-subagent), [Claude Code](/zylon-code/plugins/claude-code-subagent) |
| Developer Tools | Disabled; diagnostic access | [Session logs and debugging](/zylon-code/plugins/inspector) |
| Browser or computer control, language servers | Require explicit provider setup | [Browser](/zylon-code/plugins/browser-control), [computer](/zylon-code/plugins/computer-control), [language servers](/zylon-code/plugins/language-servers) |
| Web search | Requires a provider and credentials | [Configure search](/zylon-code/plugins/web-search) |
| Office capabilities | Depend on supplied document tools and skills | [Documents](/zylon-code/tools/documents) |

Saved settings in an existing installation can differ from these defaults. Global optional tools can extend every mode, including Minimal; a mode's built-in tool list describes its starting point. The general third-party installation dialog is hidden in this Zylon build.
