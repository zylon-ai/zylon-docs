Use the right panels to inspect files and deliverables without leaving your task. Open an item from a conversation card or the file tree, then arrange the available panels to suit your work.

| Panel | Purpose |
| --- | --- |
| Files | Browse the selected project and open files. |
| Document preview | View text, Markdown, code, images, PDF, HTML and supported Office files. |
| Terminal | Run your own interactive commands in the project. |
| Browser | Open supported web pages inside the application. |

Some previews let you choose a renderer and automatic or manual reload. Word and PowerPoint previews convert locally to PDF; spreadsheets use a dedicated viewer. If a format cannot be displayed, you may be able to open it in its usual application.

If [Zylon Diff Review](/zylon-code/plugins/diff) shows a menu when you click a file card, choose **Open as usual** to display its normal preview.

In **Settings → General → Open chat links in**, choose the in-app sidebar or your default browser for ordinary web links in chat. Modified clicks keep their usual behavior. File links open the project preview; a line reference can take you to the relevant code.

HTML preview behavior depends on **Developer view**. When enabled, a sandboxed preview can run scripts; it is not a way to grant the page access to the application or arbitrary project files. Use caution with external resources referenced by an HTML report.

## Terminal and agent commands

The terminal is for commands you type yourself. The agent's shell calls and background jobs appear separately in the conversation. A server you start in the terminal is not automatically an agent job; see [Shell and background jobs](/zylon-code/tools/shell-and-jobs).

## Browser and browser automation

Opening a web page lets you view it. For the agent to interact with a site, [browser control](/zylon-code/plugins/browser-control) must also be configured.

## Open in another application

The conversation header can offer **Open In** when a compatible application is installed on your computer. Use it to continue work in an editor or another local application.
