Consulta esta página cuando encuentres un término desconocido. El primer grupo explica cómo trabajar con modelos; el segundo, las funciones de la aplicación.

## Modelos y tareas

| Término | Significado |
| --- | --- |
| Agente | Un modelo que utiliza instrucciones y herramientas para completar una tarea. |
| Proveedor | El servicio que ejecuta el modelo seleccionado. |
| Clave API / token de acceso | Un valor secreto para autenticarse en un servicio. |
| Inicio de sesión con cuenta | Autorización mediante el acceso del propio proveedor; es distinta de una clave API y de un agente de programación externo. |
| Límite de salida por petición | Presupuesto de salida de una petición normal, que puede ser menor que la capacidad máxima del modelo. |
| Token | Una unidad de texto que procesa el modelo, a menudo parte de una palabra. Es distinto de un token de acceso. |
| Ventana de contexto | La capacidad de información de una petición, incluidas instrucciones, resultados de herramientas y la respuesta generada, según el modelo y el proveedor. |
| Llamada a herramienta | Una solicitud del modelo para realizar una operación, como leer un archivo o ejecutar un comando. |
| Conversación / sesión | Los mensajes, acciones de herramientas y estado guardados de una tarea. |
| Turno | El trabajo iniciado por un mensaje del usuario, que puede incluir varias peticiones y llamadas a herramientas. |
| Compactación | Sustituir parte del contexto activo por un resumen, conservando el historial. |
| Agente secundario | Otro agente al que se encarga una parte de la tarea principal. |

## Funciones de Zylon Code

| Término | Significado |
| --- | --- |
| Proyecto | Una carpeta de tu ordenador y sus conversaciones. Es distinto de un proyecto de Zylon Workspace en el servidor. |
| Directorio de trabajo | Carpeta actual desde la que se interpretan las rutas relativas de una conversación; puede cambiar sin sustituir el proyecto original. |
| Worktree de Git | Otra copia de trabajo del mismo repositorio, con su rama y sus propios archivos. |
| Modo | Las herramientas e instrucciones elegidas para una tarea nueva. |
| Planificación | Un estado para investigar y proponer trabajo antes de implementarlo. |
| Permiso | Restricciones de acceso y reglas de autorización de una tarea. |
| Sandbox | Restricciones de ejecución sobre archivos, procesos o acceso a la red. |
| Plugin | Una extensión que añade herramientas, comportamiento, ajustes o interfaz. |
| Paquete o bundle | Un paquete instalable que agrupa los componentes de una función. |
| Habilidad o skill | Instrucciones reutilizables para una tarea y recursos opcionales. |
| Servidor MCP | Un servicio que proporciona herramientas y recursos mediante Model Context Protocol. |
| Proceso en segundo plano | Un comando o tarea con estado y salida que puedes consultar. |
| Flujo de trabajo | Una secuencia coordinada de tareas de agentes. |
| Entregable | Un archivo presentado como resultado de una tarea. |
| Perfil | La configuración guardada de plugins y servicios de la aplicación. |
| Entorno local / Host | El proceso local que ejecuta herramientas, conecta modelos y guarda datos. |

Un nombre de modelo no implica que esté instalada la aplicación de agente de su proveedor. Estándar, PTC, Mínimo y Creador son los modos incluidos; Revisión o Reparación pueden describir una tarea o un modo personalizado.
