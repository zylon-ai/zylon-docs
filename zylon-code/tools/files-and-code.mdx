The normal presets provide tools for listing/searching paths, reading text, viewing supported images, writing files and replacing text. Minimal uses its shell for text-file work and also includes image reading. Optional global plugins can extend its tools.

## Investigate

> Find where the login form validates email addresses. Read the relevant implementation and tests. Report the files and line references without editing them.

Specify a subfolder or filename pattern when possible. Search results can be capped; an incomplete listing does not prove that no other matches exist. Ask the agent to narrow the query when output is truncated.

## Make a change

> Update the validation message in the existing implementation. Preserve unrelated changes and run the focused test. Show the resulting diff.

The agent should inspect the current file before editing. If you changed it in another editor during the task, tell the agent to re-read it. Unique text replacement can fail when the expected text is absent or appears more than once; that needs a new read, not repeated blind edits.

Relative paths resolve from the conversation's current working directory. The built-in `working_directory` tool can read that path or change to an existing directory; it does not move existing processes or expand write permissions. [Git Worktrees](/zylon-code/plugins/git-worktrees) can create a separate checkout and enter it. Files outside it need the appropriate access. An `@` mention does not bypass that restriction. Image reading also requires image-capable model metadata.

## Verify

Open the file and [review its diff](/zylon-code/everyday-use/reviewing-results). The optional [Zylon Diff Review](/zylon-code/plugins/diff) panel also lets you keep or revert changes and send comments to the agent. File tools write immediately when permitted; there is no implicit commit or automatic rollback on Stop. Use the project's normal tests and version-control workflow before releasing a change.
