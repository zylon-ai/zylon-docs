Open **Settings** at the bottom of the sidebar. General settings own the Zylon domain; Models owns its developer token and model options.

| Area | What you configure |
| --- | --- |
| General → Zylon connection | Verify or change the deployment domain and manage an explicitly trusted certificate. |
| General | Language, appearance, Developer view and defaults for new conversations. |
| Models | Save the Zylon developer token, refresh the catalog and edit model options. The Zylon model API URL is derived from the domain and read-only here. |
| Built-in plugins | Inspect loaded components and their status; this inventory is read-only. |
| Agent presets | Choose the default mode for new tasks and inspect mode configuration. |
| Plugins in the sidebar | Configure included features and optional integrations. |

## Change the Zylon domain

In **General → Zylon connection**, enter an origin such as `https://zylon.example` and select **Connect**. The app verifies the license before saving the change. A failed change to another domain preserves the working connection. If the new deployment needs a different gateway key, update it afterward in Models.

An approved private certificate can be removed with **Forget trusted certificate**. This also clears its cached license verification; reconnect using normal certificate validation or a newly verified certificate. Follow [License and access](/zylon-code/getting-started/license-and-access) if access becomes blocked.

## Developer view and defaults

**Developer view** exposes additional programming controls, including PTC and Minimal in the mode picker and advanced configuration views. It does not itself restrict what the agent can execute. Use [permissions](/zylon-code/configuration/permissions) to control task access.

Turning Developer view off resets a saved PTC or Minimal default to Standard. Existing conversations keep their mode. A new mode default applies to new tasks. Changing the model in a conversation applies to its next model request. The permission picker controls the current conversation. Check the corresponding guide before changing a default while work is running.

## Save the relevant form

Shell, Agent execution and Subagent forms keep a draft until you select **Save**. Leaving those pages without saving discards the draft. Follow any restart notice.

**Open configuration file**, when available, opens the local application configuration. Prefer the normal forms unless you need a setting they do not expose; see [Profiles and YAML](/zylon-code/advanced/profiles-and-yaml).
