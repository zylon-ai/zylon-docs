---
title: "Registro de Auditoría"
description: "Configure la captura de contenido de chat del gateway, el almacenamiento interno y la entrega externa."
---

`features.audit.enabled` controla si los logs de chat del gateway capturan mensajes de solicitud y contenido de respuesta. Está habilitado por defecto. Los eventos de Workspace, Backoffice y seguridad siguen emitiéndose cuando este flag está deshabilitado.

La captura de contenido de chat, el almacenamiento interno y la entrega externa son ajustes independientes. El almacenamiento está habilitado por defecto; la entrega por syslog y HTTP está deshabilitada por defecto.

### Configuración

| Clave | Predeterminado | Valores | Descripción |
| --- | --- | --- | --- |
| `features.audit.enabled` | `true` | `true`, `false` | Captura mensajes de solicitud y contenido de respuesta en logs de chat del gateway. |
| `logging.storage.enabled` | `true` | `true`, `false` | Persiste logs estructurados internamente para recuperarlos después. |
| `logging.delivery.syslog.enabled` | `false` | `true`, `false` | Envía logs nuevos a un colector syslog. |
| `logging.delivery.http.enabled` | `false` | `true`, `false` | Envía logs nuevos a un colector HTTP. |

### Ejemplo

Este ejemplo habilita la captura de contenido de chat del gateway y el almacenamiento interno:

```yaml
features:
  audit:
    enabled: true

logging:
  storage:
    enabled: true
```

Para instalaciones gestionadas con la CLI, combina estos ajustes con `/etc/zylon/zylon-conf.yaml` y ejecuta `sudo zylon-cli sync`.

<Note>
El contenido de chat capturado puede aparecer en logs almacenados y registros entregados externamente. Configura `features.audit.enabled: false` para omitir mensajes de solicitud y contenido de respuesta del chat del gateway. Este flag no aplica una redacción general a todos los campos de cada evento. El parámetro `include` de la API de Backoffice solo controla la recuperación; no filtra los registros entregados externamente.
</Note>

Para conectar un SIEM, sigue [Enviar logs a tu SIEM](/es/v1.58/operator-manual/configuration/features/log-delivery-storage#enviar-logs-a-tu-siem). Para programar el borrado de logs almacenados, consulta [Limpieza solo de logs](/es/v1.58/operator-manual/configuration/features/log-delivery-storage#configurar-limpieza-solo-de-logs). Habilitar solo el ejemplo anterior no reenvía logs externamente ni activa la limpieza.
