## Documented release

This manual covers **0.2.1-rc.2** of Zylon Code. Check your installed version in **Settings → General**. Your organization determines which version is available to download.

The main user-visible changes covered here are:

- **Deployment setup:** verify a licensed Zylon domain first; edit the domain in General and the developer token in Models.
- **Model access:** supported ChatGPT and Claude account sign-in, explicit private-certificate confirmation and a request output limit separate from model capacity.
- **Modes:** Developer view controls whether PTC and Minimal are offered. Minimal now supports image reading and history compaction.
- **Automation:** reminders and their task page are built in. Active task timing, names and instructions can be edited without replacing the conversation.
- **Optional plugins:** Git worktrees, persistent terminals, session search, conversation-following titles, Ralph loops and native Codex/Claude Code delegation have dedicated guides in the [catalog](/zylon-code/plugins/catalog).
- **Review and diagnostics:** revised plugin navigation, Developer Tools, detailed or compact usage statistics and Desktop font-size shortcuts.

## Before updating

Keep a backup of application data and project files, and record enabled plugins and their versions. Follow the installation or update instructions supplied for your Desktop build. Custom packages may need compatible versions; keep their source and configuration.

After updating, confirm that your Zylon connection still works and that your organization’s license is valid. If you cannot open the application or use a model, follow [setup troubleshooting](/zylon-code/troubleshooting/setup-and-models) or contact your administrator.

## Check after updating

Open representative conversations, attachments and enabled integrations. Check the selected mode, model and permissions, then try a small read-only tool task. Verify automation rules and inspect actual results, and check whether any runs need your attention. Keep originals until the updated installation works.

Use [Availability](/zylon-code/reference/availability) and [Installation](/zylon-code/getting-started/installation) for the supported distribution and prerequisites.
