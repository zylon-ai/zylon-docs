description: "Give an ongoing task a goal and distinguish its progress from plans and schedules."

A **goal** tells the agent which result to keep pursuing. A **task list** shows the steps it is taking to reach that result. Use them when work takes several turns and you want to keep its progress clear.

## Set a goal

Choose **Goal** in the message box menu or enter `/goal`, then state an outcome and a completion condition:

> Update the configuration guide to match the existing parser. Finish when every documented field has been checked and the documentation checks pass.

The goal strip lets you inspect progress, pause or resume, edit the objective and clear it. Clearing a goal leaves the conversation and files in place. Zylon Code must remain running for the agent to continue.

## Read the task list

In supported modes, the agent can track pending, active and completed steps. Use the list to follow the work, then inspect tool output and files to check the result. If the objective changes, update the goal so the old instruction does not conflict with it. If progress appears to have stopped, check whether the agent is waiting for your answer, permission or a tool result before asking it to continue.

A [plan](/zylon-code/modes/plan-mode) is a proposal to review before implementation. An [automation task](/zylon-code/plugins/automation-tasks) schedules future work. Use those features when you need approval first or a later run.
