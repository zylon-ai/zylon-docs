---
title: "Organizaciones"
description: "Lee y actualiza la organización actual de Workspace."
---

Las organizaciones son el contenedor principal de miembros del espacio de trabajo y proyectos. Estos endpoints operan sobre la organización seleccionada por el header `x-org`.

## Solicitud básica y respuesta

Obtén la organización actual con `GET /api/v1/app/organization`.

```bash
curl "https://{BASE_URL}/api/v1/app/organization" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}"
```

<Accordion title="Ejemplo de respuesta">

```json
  "name": "Aurora Labs",
  "slug": "aurora-labs",
  "state": "Active",

  "context": "Enterprise R&D and analytics.",
  "logo": "https://{BASE_URL}/files/org-logo.png",
  "auto_join_enabled": true,
  "enable_generated_resources_downloads": true,

  "default_role": "AppMember",
  "email_regex": ".*@example.com",
  "gateway_id": "gw_4b7c2a1d9e5f",
  "created_at": "2026-02-08T14:12:45Z"
}
```
</Accordion>

## Actualizar configuración de organización

```bash
curl -X POST "https://{BASE_URL}/api/v1/app/organization" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Aurora Labs",
    "context": "Private AI platform for product and support teams.",
    "clear_context": false,
    "email_regex": ".*@example.com",
    "enable_generated_resources_downloads": true,
    "enable_uploaded_resources_downloads": true
  }'
```

<Accordion title="Parametros del endpoint">
| Campo | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `name` | string | No | Nombre visible de la organización. Máximo 60 caracteres. |
| `context` | string | No | Contexto de organización usado por funcionalidades de Workspace. |
| `clear_context` | boolean | No | Ponlo a `true` para eliminar el contexto existente. Por defecto es `false`. |
| `email_regex` | string | No | Regex valida para los emails de la organizacion. |
| `enable_generated_resources_downloads` | boolean | No | Permite descargar recursos generados. Omite o envia null para mantener el ajuste. |
| `enable_uploaded_resources_downloads` | boolean | No | Permite descargar recursos subidos. Omite o envia null para mantener el ajuste. |
| `logo_file_name` | string | No | Nombre del archivo de logo en multipart. Obligatorio si subes un logo. |
| `logo_content_type` | string | No | Tipo de contenido del logo en multipart. Debe ser PNG o JPEG. |
| `logo_content_length` | integer | No | Tamaño del logo en bytes. Máximo 5 MB. |
| `fileData` | file | No | Binario del logo solo para multipart. |
</Accordion>

```json
  "id": "org_2f3a9d1c7b5e4a8f",
  "name": "Aurora Labs",
```

## Campos de respuesta de organizacion

GET y POST devuelven el mismo modelo. Los campos nulos pueden omitirse. La politica de descarga afecta a artefactos y descargas/exportaciones de archivos del hilo; las descargas deshabilitadas devuelven `403`.

| Campo | Tipo | Significado |
| --- | --- | --- |
| `id` | string | ID de organizacion. |
| `name` | string | Nombre. |
| `slug` | string | Slug del espacio para `x-org`. |
| `state` | string | `Active`, `Inactive`. |
| `display_name` | string | Nombre visible. |
| `context` | string or null | Instrucciones de organizacion. |
| `logo` | string or null | URL publica del logo. |
| `auto_join_enabled` | boolean | Adhesion automatica habilitada. |
| `enable_generated_resources_downloads` | boolean | Politica de descarga de recursos generados. |
| `enable_uploaded_resources_downloads` | boolean | Politica de descarga de recursos subidos. |
| `default_role` | string | `AppGuest`, `AppMember`, `AppAdmin`, `AppOwner`. |
| `email_regex` | string | Regex de emails. |
| `gateway_id` | string | ID de gateway de la organizacion. |
| `created_at` | timestamp | Fecha de creacion generada por el servidor. |
| `member_count` | integer or null | Numero de miembros opcional; estas rutas de organizacion actual no lo incluyen. |

## Errores y casos límite

- **401/403**: token inválido o ausente.
- **400**: regex inválida, nombre de organización de más de 60 caracteres, tipo de logo no soportado o logo mayor de 5 MB.
