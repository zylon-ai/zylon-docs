Plan mode lets you investigate a task and review a proposal before implementation. It is available in Standard, PTC and Creator.

## Request a plan

Choose **Plan** in the **+** menu or enter `/plan`, then explain the outcome:

> Plan how to add pagination to the search results. Inspect the existing API and components. Propose changes, edge cases, tests and completion criteria. Do not implement it yet.

The agent should inspect the project without modifying it and ask about decisions it cannot resolve from the available information. Answering these questions does not approve implementation.

## Review and proceed

The plan appears as a card with review controls. Its full document may open automatically in the right panel; use **Open** or **View full plan** to read it again. Closing the preview does not approve implementation. Check what the plan includes, what it assumes, which files it affects and how the result will be tested. Use its controls to approve implementation or request revisions.

If the review controls are unavailable, use the planning controls to leave Plan mode and check the mode indicator before asking the agent to carry out the plan. Agreement in the chat alone does not end the planning state.

## Select permissions too

Tools can remain available while planning. Choose an appropriate [permission preset](/zylon-code/configuration/permissions), such as Read Only, when you want execution restrictions during the investigation. Minimal does not include integrated planning.
