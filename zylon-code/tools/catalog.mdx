You normally request an outcome in natural language. The agent chooses tools from the active catalog; names below help you recognize their recorded calls. Your mode, plugins and permissions determine availability.

| Capability / names | Purpose and guide |
| --- | --- |
| `read`, `read_image`, `write`, `edit`, `glob`, `grep` | [Inspect and change project files](/zylon-code/tools/files-and-code). Images need model support. |
| `bash`, `pwsh`; `job_list`, `job_output`, `job_kill` | [Commands and background jobs](/zylon-code/tools/shell-and-jobs). OS and mode choose the shell. |
| `web_fetch`; optional `web_search` | [Read URLs](/zylon-code/tools/web); [search](/zylon-code/plugins/web-search) needs a configured provider. |
| `skill` | Load [reusable instructions](/zylon-code/customization/skills). |
| `ask_user_question`, `exit_plan_mode`, `todo_write`, `create_goal`, `get_goal`, `update_goal` | [Questions/planning](/zylon-code/modes/plan-mode) and [task progress](/zylon-code/everyday-use/goals-and-task-lists). |
| `subagent`, `subagent_fork`, `list_subagent_models`, `list_agents`, `interrupt_agent` | [Delegate and inspect work](/zylon-code/agents/delegation). |
| `workflow` | [Orchestrate an explicitly requested workflow](/zylon-code/tools/workflows). |
| `run_code` | [Programmatic tool calling](/zylon-code/modes/ptc). |
| `diff_approval_annotate` | [Review annotations](/zylon-code/plugins/diff), when Diff Review is enabled. |
| `present` | [Present generated files](/zylon-code/everyday-use/reviewing-results). |
| `cordis_inspect_list`, `cordis_inspect_query`, `plugin_manager` | [Creator inspection and installation](/zylon-code/modes/creator). |
| `mcp__<server>__<tool>`, `list_mcp_resources`, `list_mcp_resource_templates`, `read_mcp_resource` | [MCP services](/zylon-code/plugins/mcp); server tools use their own names. |
| `spawn_teammate`, `send_message`, `wait_agent`, `team_task_create`, `team_task_get`, `team_task_list`, `team_task_update` | [Teammates, messages and shared tasks](/zylon-code/plugins/agent-teams). |
| `stagehand_navigate`, `stagehand_observe`, `stagehand_act`, `stagehand_extract`, `stagehand_screenshot`, `stagehand_tabs`; DevTools tools | [Browser automation](/zylon-code/plugins/browser-control); provider-specific catalog. |
| Computer-use tools | [Desktop control](/zylon-code/plugins/computer-control); runtime/OS permissions required. |
| `lsp` | [Optional symbol navigation](/zylon-code/plugins/language-servers). |
| `terminal_open`, `terminal_list`, `terminal_read`, `terminal_send`, `terminal_signal`, `terminal_close` | [Persistent terminals](/zylon-code/tools/shell-and-jobs), when configured. |
| `schedule_create`, `schedule_list`, `schedule_update`, `schedule_delete` | [Automated follow-ups](/zylon-code/plugins/automation-tasks), when enabled. |
| `session_search`, `session_trace`, `session_event_read`, `session_event_search`, `session_event_trace` | Inspect saved conversation events in configurations that expose session-query tools. See [conversations](/zylon-code/everyday-use/conversations). |
| `load_workspace_dependencies` | Discover a prepared document/runtime environment. See [documents](/zylon-code/tools/documents). |
| `str_replace_editor`, `ralph` | Optional alternative file editor and iterative workflow with limits. See [files](/zylon-code/tools/files-and-code) and [workflows](/zylon-code/tools/workflows). |

Some tools in this reference require an optional integration; they are not all available in every chat. The installed tool catalog and [availability guide](/zylon-code/reference/availability) identify what your deployment exposes.

A successful tool call is different from the model's description of it. Expand the result and inspect errors, cancellation and output limits. For a missing tool, check mode, enabled plugins and prerequisites before requesting broader permissions.
