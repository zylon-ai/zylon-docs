Habilita la gestión de cuotas en Backoffice para configurar límites de solicitudes y tokens para cuentas y gateways, consultar el consumo y restablecer las cuotas.

### Configuración

| Clave | Predeterminado | Valores | Descripción |
| --- | --- | --- | --- |
| `features.quotas.enabled` | `false` | `true`, `false` | Habilita la gestión de cuotas y límites de uso en Backoffice. Requiere un backend compatible con cuotas. |

### Ejemplo

Añade lo siguiente a tu archivo de configuración de Zylon:

```yaml
features:
  quotas:
    enabled: true
```

Ejecuta `sudo zylon-cli sync` después de cambiar la configuración.

Cuando está habilitada, la gestión de cuotas está disponible en **Backoffice > Plataforma > Cuotas**. Cuando está deshabilitada, la opción de navegación se oculta y no se puede acceder directamente a las páginas de cuotas.

### Gestionar cuotas

Sigue la [guía de cuotas para Operadores](/es/v1.58/operator-manual/backoffice/quotas) para crear límites, elegir qué ocurre al alcanzarlos, asignar cuotas a cuentas o gateways y consultar o restablecer el consumo.

<Note>
  El ajuste habilita la interfaz de gestión. Define los límites y asigna la cuota en Backoffice; habilitar el ajuste por sí solo no define una política de cuotas.
</Note>
