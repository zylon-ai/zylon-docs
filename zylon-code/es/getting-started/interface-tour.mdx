La barra izquierda contiene tus proyectos y conversaciones. En el centro están la conversación y el cuadro donde escribes los mensajes. Los paneles de la derecha permiten abrir archivos, revisar resultados y utilizar un terminal o un navegador.

| Zona | Qué puedes hacer |
| --- | --- |
| Proyectos y conversaciones | Abrir un proyecto, iniciar una conversación y encontrar trabajos anteriores. |
| Cuadro de mensajes | Escribir una petición, adjuntar archivos y elegir modelo, modo y permisos. |
| Selector de modelo | Elegir el modelo que atenderá la siguiente petición. |
| Selector de modo | Elegir cómo trabaja el agente en una tarea nueva. Empieza por Estándar. |
| Selector de permisos | Elegir qué puede hacer el agente, como leer archivos o editar el proyecto. |
| Tarjetas de herramientas | Consultar qué ha pedido el agente, qué se ha ejecutado y cuál ha sido el resultado. |
| Paneles derechos | Abrir archivos, revisar resultados y ejecutar tus propios comandos. |
| Plugins | Activar funciones y configurar integraciones. |
| Ajustes | Cambiar idioma, apariencia, conexiones de modelos y valores predeterminados. |

Para cambiar el dominio de Zylon, abre **Ajustes → General**. Para actualizar la clave de API o las conexiones de modelos, abre **Ajustes → Modelos**. Consulta [Ajustes](/zylon-code/es/configuration/settings) para conocer las demás opciones.

## Escribe una petición

Pulsa **+** para abrir el menú de adjuntos. Escribe `/` para ver los comandos y las habilidades disponibles, o `@` para hacer referencia a archivos, carpetas o servidores MCP conectados. Los [servidores MCP](/zylon-code/es/plugins/mcp) permiten al agente utilizar herramientas y servicios adicionales. Las opciones dependen del modo y los plugins que estés utilizando.

## Sigue el trabajo

Despliega una tarjeta de herramienta para ver qué archivo ha leído el agente, qué comando ha ejecutado o qué resultado ha obtenido. Si te hace una pregunta o pide permiso, lee la solicitud y responde con los controles que aparecen. Puedes [detener la tarea o darle nuevas indicaciones](/zylon-code/es/everyday-use/conversations) mientras trabaja.

Continúa con [Proyectos](/zylon-code/es/everyday-use/projects) y sigue las páginas de uso diario en orden. Puedes consultar los [atajos de teclado](/zylon-code/es/reference/keyboard-shortcuts) cuando los necesites.
