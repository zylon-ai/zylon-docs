A project is a folder on your computer. Zylon Code groups its conversations together and uses that folder as the working directory for tools. Adding a project registers the folder; it does not upload your repository or create a Zylon Workspace project.

## Add a project

1. Open the project chooser from the welcome area or sidebar.
2. Select an existing folder.
3. Check its full path and start a conversation.

For a Git repository, choose the repository's root folder so the agent can find its instructions, source files and tests.

## Organize your work

Use the project menu to change its displayed name or remove it from the list. Removing the entry does not delete the folder. The sidebar can group chats by project or display them in one list. Pin important chats and search for others by title.

Choose **Manual order** if you want to arrange entries yourself, or **Last updated** to bring recent work to the top. Changing the sorting option can replace your saved manual layout.

## Check the selected folder

If you are unsure where the agent is working, ask:

> Show the working directory and the files in its top-level folder. Do not change anything.

Compare the path with your project selection. Start a conversation in the correct project if it differs. Next, read [Conversations](/zylon-code/everyday-use/conversations).
