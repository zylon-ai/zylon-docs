Standard is the default Zylon Code mode. The agent calls tools directly to read and edit files, search and run commands. It includes project instructions, skills, planning, goals, subagents, workflows and context compaction.

## Start a task

Select Standard before the first message. State the desired outcome, relevant files, restrictions and how to check the result:

> Find why submitting the search form twice clears the results. Fix the cause, run the relevant existing tests and explain the changed files. Ask before installing dependencies.

For this example, check that the answer explains the cause, the changed files and the tests actually run. Open the changed-files card and tool results to verify them. If a test could not run, ask what prevented it and what remains unchecked.

## More than coding

Standard can also summarize notes, create documents and write batch scripts. PTC is not required just because the task processes many files. Optional browser, computer, search and MCP capabilities require their own setup; selecting Standard does not install them.

Use [Plan mode](/zylon-code/modes/plan-mode) when you want a proposal first. Use [project instructions](/zylon-code/customization/project-instructions) for repository conventions and [delegation](/zylon-code/agents/delegation) for independent subtasks. Tools remain subject to the selected permissions and external prerequisites.
