Las integraciones de SharePoint importan bibliotecas y documentos. **Habilita SharePoint a nivel de instancia primero**—consulta la guía del operador: [Configuración de SharePoint](/es/operator-manual/knowledge-base/sharepoint).

Usa el flujo de [OpenID y OAuth](/es/developer-manual/build-with-zylon/workspace-api/authentication/openid) para crear o volver a autenticar el artefacto de integración. Los tokens se guardan como propiedades privadas y no se devuelven en la API pública de artefactos.

## Obtener la integración

<Accordion title="Parametros del endpoint">
| Tipo | Nombre | Obligatorio | Notas |
| --- | --- | --- | --- |
| Path | `integrationArtifactID` | Si | ID del artefacto de integración SharePoint. |
</Accordion>

```bash
curl "https://{BASE_URL}/api/v1/app/artifact/{integrationArtifactID}" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}"
```

## Iniciar la ingesta

Indica el proyecto de destino y los elementos que quieres importar. Cada elemento necesita el ID de la unidad y el ID del archivo o carpeta. La respuesta es un stream de Server-Sent Events (SSE).

<Accordion title="Parametros del endpoint">
| Tipo | Nombre | Obligatorio | Notas |
| --- | --- | --- | --- |
| Path | `integrationArtifactID` | Si | ID del artefacto de integración SharePoint. |
| Body | `project_id` | Si | Proyecto de destino. |
| Body | `items` | Si | Elementos de SharePoint que se importarán. |
| Body | `items[].drive_id` | Si | ID de la unidad de SharePoint. |
| Body | `items[].id` | Si | ID del archivo o carpeta. |
</Accordion>

```bash
curl -N -X POST "https://{BASE_URL}/api/v1/app/artifact/{integrationArtifactID}/ingest" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}" \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{
    "project_id": "{projectID}",
    "items": [
      {
        "drive_id": "{driveID}",
        "id": "{itemID}"
      }
    ]
  }'
```

<Accordion title="Ejemplo de stream">
```text
event: SyncEvent
data: {"type":"sync_started","current_artifact_count":0,"integration_item_count":1}

event: SyncEvent
data: {"type":"sync_progress","artifact_id":"{artifactID}","op":"Added","progress":1.0}

event: SyncEvent
data: {"type":"sync_completed"}
```
</Accordion>

## Errores y casos límite

- **400**: faltan `project_id`, `items` o alguno de sus IDs.
- **403**: integración no habilitada o permisos insuficientes.
- **404**: proyecto, elemento o artefacto de integración no encontrado.
