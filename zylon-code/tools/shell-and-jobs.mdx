The agent runs commands on your computer. The default setup uses Bash on macOS and PowerShell on Windows. In Standard, a new execution starts with a fresh shell; it does not retain the previous shell's state. Minimal keeps a shell open between executions.

## Ask for a check

> Read this project's scripts and run the existing test for the changed package. Report the command, output and exit status. Do not install dependencies.

Check the working directory and command in the tool card. If a command cannot be found, check that it is installed and available to the application. A timeout or cancellation does not mean a test passed.

## Follow background work

When supported, the agent can start a command as a background job. Its ID and status appear in the job list. Ask the agent to list jobs, read output or stop a particular job. Stopping it leaves completed changes in place.

Retained output is limited. Ask for an explicit log file when you need the complete output of a long command.

The optional [Persistent terminals](/zylon-code/plugins/persistent-terminals) plugin lets an agent open and revisit its own terminals in any mode. Changing the conversation's working directory affects new commands; terminals and servers already running keep their own directory.

## Set command limits

Open **Plugins → Built-in plugin settings → Shell** to change command duration and output limits, then Save. Raising retained output uses more memory and does not increase the model's context window.

The [terminal panel](/zylon-code/everyday-use/panels) is for commands you run yourself. Project executables and corporate network access must be available on your computer.
