---
title: "Analytics"
description: "Track usage totals, rankings, and time series metrics."
---

Analytics endpoints summarize how your workspace is being used across projects and users.

## Basic request and response

Start with totals to get a usage snapshot from `GET /api/v1/app/organization/analytics/totals`.

```bash
curl "https://{BASE_URL}/api/v1/app/organization/analytics/totals" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}"
```

<Accordion title="Example response">
```json
{
  "projects_total": 12,
  "threads_total": 184,
  "interactions_total": 1420,
  "agent_flows_total": 36,
  "uploaded_artifacts_total": 87
}
```
</Accordion>

## Active users ranking

<Accordion title="Endpoint parameters">
| Type | Name | Required | Notes |
| --- | --- | --- | --- |
| Query | `start_date` | No | Start of the reporting window as Unix epoch milliseconds. |
| Query | `end_date` | No | End of the reporting window as Unix epoch milliseconds. |
| Query | `limit` | No | Maximum number of ranked users to return. Defaults to `5`. |
</Accordion>

```bash
curl "https://{BASE_URL}/api/v1/app/organization/analytics/ranking/active-users?start_date=1769990400000&end_date=1771804800000&limit=5" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}"
```

## Time series

Both date bounds are required. Results are weekly counts at seven-day intervals starting on the requested start date.

<Accordion title="Endpoint parameters">
| Type | Name | Required | Notes |
| --- | --- | --- | --- |
| Query | `start_date` | Yes | Start of the reporting window as Unix epoch milliseconds. |
| Query | `end_date` | Yes | End of the reporting window as Unix epoch milliseconds. |
| Query | `type` | Yes | `Thread`, `Interactions`, `artifact_agent_flow`, or `artifact_document`; case-insensitive. |
</Accordion>

```bash
curl "https://{BASE_URL}/api/v1/app/organization/analytics/timeseries?start_date=1769990400000&end_date=1771804800000&type=interactions" \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "x-org: {org_slug}"
```

<Accordion title="Example response">
```json
[
  { "date": "2026-02-02", "value": 18 },
  { "date": "2026-02-09", "value": 25 },
  { "date": "2026-02-16", "value": 21 },
  { "date": "2026-02-23", "value": 19 }
]
```
</Accordion>

## Errors and edge cases

- **400**: invalid date range or type.
- **403**: insufficient permissions.
