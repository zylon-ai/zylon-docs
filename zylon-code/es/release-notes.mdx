## Zylon Code 0.1

Este manual cubre la aplicación de escritorio, la interfaz en español e inglés, la conexión de modelos de Zylon, los modos incluidos y las integraciones opcionales. El modo inicial es Estándar y la conexión de Zylon empieza con `zylon/default`.

Consulta [Disponibilidad](/zylon-code/es/reference/availability) para comprobar los requisitos de una función. El enlace de descarga y los pasos se añadirán a [Instalación](/zylon-code/es/getting-started/installation) junto con la información de distribución para clientes.

## Antes de actualizar

Anota las versiones de la aplicación y los plugins instalados. Sal de Zylon Code por completo y haz una copia de sus datos y de las carpetas de proyecto. Lee los cambios de la versión y las instrucciones de migración, si las hay.

Después, comprueba conversaciones, credenciales, adjuntos y plugins activados. Conserva los originales hasta confirmar que la actualización funciona. Los paquetes personalizados pueden necesitar ajustes de compatibilidad; guarda su código e instrucciones.

Esta página describe la versión documentada. Las fechas, enlaces de descarga y procedimientos de actualización deben corresponder a la información suministrada con cada versión para clientes.
