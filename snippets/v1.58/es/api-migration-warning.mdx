<Warning>
**Cambios incompatibles en la API de 1.58**

Antes de actualizar una integración desde 1.57, sigue la [guía de migración de API](/es/v1.58/developer-manual/build-with-zylon/workspace-api/api-migration-1-57-to-1-58). La versión 1.58 cambia las rutas y los cuerpos de contenido de artefactos, los IDs de cuenta y de miembro del espacio de trabajo, y los bloques de respuesta de herramientas del servidor en los mensajes de Workspace y ZylonGPT. Las rutas antiguas no conservan todo el contrato de 1.57 y quedan obsoletas, con eliminación prevista para 1.59.
</Warning>
