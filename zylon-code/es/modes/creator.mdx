Creador te ayuda a crear herramientas, funciones de interfaz y modos propios. Incluye las capacidades generales de Estándar y herramientas para inspeccionar la aplicación instalada y crear extensiones.

## Describe la función

Inicia una conversación en Creador e indica el comportamiento, los ajustes, los permisos y una forma de comprobarlo:

> Crea un modo llamado Revisión que inspeccione los cambios e informe de problemas sin editar archivos. Instálalo como paquete de plugins local. Comprueba sus herramientas en una conversación nueva y explica cómo desactivarlo.

Pide una instalación que funcione y una comprobación, para poder revisar la función además del código generado. Creador debe consultar las API disponibles e informar de errores de instalación o activación.

## Revisa y conserva el resultado

Consulta los archivos creados y la solicitud de instalación. Localiza el paquete en Plugins, inicia una tarea que lo utilice y comprueba su comportamiento. Las conversaciones existentes conservan las herramientas con las que empezaron.

Guarda el código y las instrucciones para reinstalar, actualizar y desactivar la función. Un plugin generado ejecuta código local y necesita comprobarse cuando cambie la aplicación.
