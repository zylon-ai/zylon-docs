El **Registro de credenciales** ofrece a los operadores del espacio de trabajo una vista central de las credenciales de conectores que utilizan los usuarios en todo el espacio de trabajo y sus proyectos. Úsalo para revisar quién creó una conexión, dónde se utiliza y cuándo se creó.

![Registro de credenciales](/images/user-manual/credential-registry.png)

## Qué puedes gestionar

El Registro de credenciales incluye conexiones para:

- Integraciones externas, como Confluence, SharePoint, Claromentis, File System y Google Drive.
- Servidores MCP.
- Conectores de bases de datos.

El registro se administra a nivel de plataforma, por lo que los operadores pueden encontrar desde un único lugar las credenciales utilizadas en todas las organizaciones y proyectos disponibles, incluidos los proyectos privados o no gestionados. El registro no muestra los valores secretos.

Las conexiones se crean dentro de los proyectos, no desde el Registro de credenciales. El registro es un inventario administrativo de solo lectura para revisar y controlar las conexiones existentes.

## Buscar una credencial

Abre **Registro de credenciales** desde el área de plataforma. Usa los filtros disponibles para limitar la lista por:

- **Organización**.
- **Estado del usuario**, para encontrar credenciales creadas por usuarios activos o inactivos.
- **Fecha**, para seleccionar un intervalo de fechas de creación.
- **Buscar**, para buscar por el nombre de la credencial o del conector.

La tabla muestra el nombre del conector, la organización, el tipo, el proyecto, quién lo creó, el estado de esa persona y la fecha de creación. Selecciona la flecha al final de una fila para abrir los detalles de la credencial.

## Revisar los detalles de una credencial

El panel de detalles incluye:

- El nombre y el tipo de la credencial.
- El proyecto en el que se utiliza el conector.
- La persona que creó la credencial y su estado actual.
- La fecha de creación.
- El estado actual de la credencial.

## Revocar un conector

Para impedir que se utilice un conector:

1. Abre los detalles de la credencial.
2. Selecciona **Revocar credenciales**.
3. Revisa el mensaje de confirmación y selecciona **Sí, revocar**.

Revocar las credenciales desactiva la conexión para los usuarios y proyectos que la utilizan. No elimina los archivos ni los datos que ya se hayan añadido mediante el conector. El contenido existente seguirá disponible en el espacio de trabajo, pero el conector no podrá utilizarse para acceder a contenido nuevo o incorporarlo hasta que se configure de nuevo.

> La revocación afecta a la credencial del conector seleccionada en todo su uso dentro del espacio de trabajo. Confirma la organización, el proyecto y la persona creadora antes de revocar el acceso.

Revocar una credencial no es lo mismo que eliminar un proyecto ni que borrar el contenido incorporado anteriormente. La acción del registro desactiva el conector, pero no elimina los archivos ni los datos del espacio de trabajo.

## Requisitos de acceso

El Registro de credenciales está disponible para los operadores de plataforma autorizados. Si la función está desactivada en tu plataforma, contacta con el administrador de Zylon.
