Despliega la tarjeta de la herramienta que ha fallado y lee la acción solicitada y su resultado antes de cambiar permisos.

| Síntoma | Qué hacer |
| --- | --- |
| La configuración de licencia bloquea el modelo y las herramientas | Comprueba el dominio y la licencia de Zylon; los permisos de archivos no resuelven un fallo de licencia. |
| Falta una herramienta | Comprueba el modo y los plugins activados. Confirma que su proveedor esté configurado. |
| Se bloquea un cambio en un archivo | Abre el selector de permisos y revisa la ruta de destino y las restricciones de acceso. |
| No se encuentra un comando | Comprueba que el ejecutable esté instalado y disponible para la aplicación en este ordenador. |
| Se agota el tiempo de un comando | Revisa el límite de duración y pide al agente que enumere los procesos para saber si el comando sigue en marcha. |
| Una edición no encuentra el texto | Pide al agente que vuelva a leer el archivo actual antes de reintentar. |
| No se puede utilizar una captura | Elige un modelo que admita imágenes. Si falla la propia captura, revisa la configuración del control del navegador o del ordenador. |
| Falla una vista previa de Office | Conserva el archivo editable, prueba a abrirlo en su aplicación habitual y comprueba qué formatos puede mostrar tu versión. |
| Tú puedes navegar, pero el agente no | Configura la automatización: abrir el panel de navegador no la activa. |

## Comprueba la causa antes de ampliar permisos

Pide una comprobación más pequeña de solo lectura o una explicación del requisito que falta. Ampliar los permisos no instala una herramienta, conecta un proveedor ni añade una función que no esté disponible.

Por ejemplo:

> Explica por qué ha fallado el comando. Comprueba si ha modificado archivos o ha dejado algún proceso en marcha. No lo repitas ni cambies los permisos todavía.

Antes de reintentar, revisa los archivos y los procesos para saber qué acciones se han completado. Aprueba únicamente la operación cuyo destino y efectos aceptes.

Consulta [Permisos](/zylon-code/es/configuration/permissions), [Shell](/zylon-code/es/tools/shell-and-jobs), [Documentos](/zylon-code/es/tools/documents) y la guía del plugin afectado. Si se ha recortado la salida, acota la petición para obtener el resultado que falta.
