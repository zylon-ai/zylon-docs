The optional **Developer Tools** bundle is for troubleshooting and development. It starts disabled. Enable it from **Plugins → Experimental plugins** only when you need its diagnostic access.

## Inspect a conversation

Use the sidebar's new-tab menu to open **Session Log**. Its **Raw Log** and **Chat Group** presentations let you inspect the recorded conversation and grouped messages. Use the normal conversation or Trajectory view first when those already show the information you need.

**Ctrl/Cmd+Shift+.** opens or collapses **NodeJS Inspector** in the bottom panel. This debugger examines the application's local runtime.

<Warning>
Enabling Developer Tools starts a debugging backend and unredacted capture of Host network requests. A debugger can execute code and expose credentials, prompts and private files. Keep access local and review diagnostics before sharing them.
</Warning>

## Finish the investigation

Begin with [Recovery and support reports](/zylon-code/troubleshooting/recovery), reproduce the specific failure and collect only what support needs. Close the debugger and turn off Developer Tools afterward. Disabling does not make an already exported diagnostic file safe to share; remove credentials and private data from the copy you send.
