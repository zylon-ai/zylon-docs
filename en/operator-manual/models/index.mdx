## How the hardware is sized

- **48GB, 96GB, 560GB, 1120GB**: total GPU memory needed. Set `ai.gpuCount` to the number of GPUs: the model is split across all of them, so their combined memory must reach that size (for example 4 x 141GB for 560GB).
- **DGX Spark**: one NVIDIA DGX Spark.

Models ship as NVFP4: Blackwell GPUs run them natively, older GPUs such as Hopper run them more slowly. Where a model also has an AWQ or GPTQ build, set `ai.quantization: awq` or `gptq` to use it instead.

All presets, including base, alternative and deprecated ones, are listed in the [AI presets reference](/en/operator-manual/ai-presets/presets).
