Zylon Companion is an optional floating helper for following chat activity. It shows recent work, running tasks, pending questions and recorded results. Enable **Zylon Companion** under **Plugins → Experimental plugins**.

## Follow and open work

Click the companion to open its activity bubbles. From an item, open the associated conversation, dismiss a notification or send a follow-up. Its compact composer can also start a new chat in the selected project.

For example, keep the helper visible while working in another application, then open the linked chat when the agent needs an answer. Sending a message starts a normal model task. The companion's animation itself makes no model requests.

## Arrange the helper

Drag it to move it. Its controls adjust visibility and size and provide supported wave or jump actions. It uses a separate transparent Desktop window, so it can remain visible while the main application window is minimized or closed to the background.

If you quit Zylon Code, the companion closes too. Disabling the plugin removes the helper while keeping your ordinary conversations. Open the associated chat to answer a pending question or approval.
