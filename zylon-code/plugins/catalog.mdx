Plugins add tools, settings or interface features to Zylon Code. Some are already part of the application; others are included but start disabled. An installable **bundle** groups the components a feature needs.

| Feature | Initial availability | Guide |
| --- | --- | --- |
| Shell | Included | [Commands and limits](/zylon-code/tools/shell-and-jobs) |
| Agent execution | Included | [Parallel tool calls](/zylon-code/plugins/agent-loop) |
| Subagents | Standard, PTC and Creator | [Models and limits](/zylon-code/agents/models-and-limits) |
| Zylon MCPs | Enabled, with no servers configured | [MCP Manager](/zylon-code/plugins/mcp) |
| Zylon Diff Review | Included, disabled | [Review changes and send comments](/zylon-code/plugins/diff) |
| Automation tasks | Included, disabled | [Schedule work](/zylon-code/plugins/automation-tasks) |
| Agent Teams | Included, disabled; experimental | [Shared team tasks](/zylon-code/plugins/agent-teams) |
| Auto Authorization Review | Included, disabled; experimental | [Review permissions](/zylon-code/plugins/auto-authorization-review) |
| Zylon Companion | Included, disabled; experimental | [Floating helper](/zylon-code/plugins/companion) |
| Browser control | Requires a configured provider | [Browser automation](/zylon-code/plugins/browser-control) |
| Computer control | Requires a provider and operating-system permissions | [Desktop interaction](/zylon-code/plugins/computer-control) |
| Web search | Requires a provider and credentials | [Exa and Perplexity](/zylon-code/plugins/web-search) |
| Language servers | Requires a configured language server | [Symbol navigation](/zylon-code/plugins/language-servers) |
| Inspector | Optional support/developer feature | [Diagnostics](/zylon-code/plugins/inspector) |
| Office capabilities | Depend on included document tools and skills | [Documents](/zylon-code/tools/documents) |

Saved settings in an existing installation take precedence over new-installation defaults. Use **Plugins** to see the features available in your build. The built-in inventory also lists internal components; you do not need to install each one separately.

Continue with [Manage plugins](/zylon-code/plugins/managing-plugins).
