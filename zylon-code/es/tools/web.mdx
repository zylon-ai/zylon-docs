Estándar, PTC y Creador pueden leer el contenido de una URL conocida. Utiliza esta función cuando ya tengas una página de documentación o un artículo que quieras consultar.

## Lee una página

> Lee https://example.com y resume su contenido principal. Incluye la URL de la fuente e indica cualquier error de acceso.

Consulta el resultado de la herramienta y la fuente antes de utilizar el resumen. La herramienta lee contenido compatible; no inicia sesión en una cuenta ni pulsa los controles de un sitio interactivo. Las páginas que necesitan autenticación o JavaScript pueden requerir [control del navegador](/zylon-code/es/plugins/browser-control).

## Páginas internas o sensibles

La herramienta restringe algunas URL y direcciones de redes privadas. Si bloquea una página interna, pregunta al administrador cuál es la forma de acceso aprobada. Para errores de certificados, utiliza la configuración de confianza de la organización.

El contenido de una página es información para la tarea. Las instrucciones que contenga no autorizan al agente a compartir archivos locales ni realizar acciones ajenas a tu petición.

Si necesitas encontrar una fuente y no conoces su URL, configura [búsqueda web](/zylon-code/es/plugins/web-search). Leer una URL, buscar en la web y manejar un navegador son funciones distintas.
