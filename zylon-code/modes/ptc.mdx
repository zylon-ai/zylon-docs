title: "PTC"
description: "Process files in batches and combine results with a program written by the agent."

---

PTC means *Programmatic Tool Calling*: calling tools from a program. The agent writes a TypeScript program to coordinate work such as checking many files or combining results into a report. You describe the task; you do not need to write the program yourself.

Choose PTC before starting the conversation. If it is missing, enable **Settings → General → Developer view**.

## Example

> Check JSON files in configs/ against schema.json. Save a CSV with one row per issue. Include unreadable files and continue checking the rest. Leave the originals unchanged.

The program can check files one by one, handle individual failures and combine results. It can pass selected results to the model instead of every intermediate output. You can inspect its tool activity in the conversation, and the usual permissions still apply.

## Inspect the result

Expand the execution to inspect the program and the tools it used. Check whether failed files were included rather than silently skipped. Open the CSV and compare a few rows with the inputs. Request bounded output instead of asking the program to print every intermediate result.

## Limits

PTC has skills, instructions, goals, planning, delegation and compaction. It does not include the workflow tool. It does not promise lower token use or better performance than Standard: results depend on the task and program. Tool availability, filesystem access and approval policy still apply.

Choose [Standard](/zylon-code/modes/standard) for direct tools or read [workflows](/zylon-code/tools/workflows) for the separate reusable workflow feature.
