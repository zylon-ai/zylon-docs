description: "Comprueba el dominio y la licencia de Zylon y guarda una clave del gateway para acceder a sus modelos."

La configuración tiene dos pasos: comprobar el **dominio y la licencia de Zylon** y guardar un **token de desarrollador** para acceder a los modelos. La licencia no sustituye a la clave de API, y la clave no activa una licencia.

## 1. Conecta el dominio de Zylon

En la bienvenida, introduce el **Dominio de Zylon**, por ejemplo `https://zylon.example`, y pulsa **Conectar**. Utiliza la dirección HTTP o HTTPS que te facilite el administrador, con el puerto si hace falta. No añadas una ruta de API, credenciales ni parámetros.

| Dirección | Dónde se utiliza |
| --- | --- |
| `https://zylon.example` | Dominio de Zylon en la bienvenida o en Ajustes → General. |
| `https://zylon.example/api/gpt` | URL de los modelos, que la aplicación calcula y muestra automáticamente. |

Las instrucciones de Backoffice pueden mostrar la URL completa de los modelos. Si indican `https://zylon.example/api/gpt`, escribe solo `https://zylon.example` en **Dominio de Zylon**.

La bienvenida se cierra cuando la aplicación comprueba una licencia vigente que incluye Zylon Code. Este paso no se puede omitir. Para cambiar el dominio más adelante, abre **Ajustes → General → Conexión con Zylon**. Si falla la comprobación, consulta [Licencia y acceso](/zylon-code/es/getting-started/license-and-access).

Si el servidor utiliza un certificado privado, puede aparecer una confirmación con el servidor, la huella, el emisor y las fechas de validez. Contrasta esos datos con el administrador antes de pulsar **Confiar y conectar**. La autorización corresponde a ese certificado y dominio.

## 2. Crea una clave de API del gateway

1. En Backoffice, abre **Consola de desarrollo** y selecciona el gateway que te proporcione la organización.
2. Abre **Claves de API** y pulsa **Nueva clave de API**.
3. Escribe un nombre, elige **Lectura y escritura** y establece una fecha de caducidad adecuada.
4. Crea la clave y cópiala enseguida. El valor secreto solo se muestra una vez.

Tu cuenta necesita acceso de Desarrollador y acceso al gateway. Si te faltan, pídeselos al administrador. Cuando hay descargas disponibles, el diálogo de creación también incluye las instrucciones para instalar Zylon Code.

Utiliza una clave del **gateway**, no un token exclusivo de Workspace. La [guía de tokens de la plataforma](/es/v1.58/developer-manual/get-started/token-management) explica los tipos de token y su gestión.

## 3. Guarda la clave en Desktop

Abre **Ajustes → Modelos**, busca la conexión de Zylon y pega la clave en **Token de desarrollador**. La **URL de los modelos** es de solo lectura; el dominio se cambia en General. Pulsa **Guardar conexión**.

Antes de guardar, la aplicación consulta los modelos para comprobar la clave. Si editas una conexión que ya funciona, deja el token vacío para conservar la clave guardada. Si falla la consulta, se mantienen los ajustes, el token y el catálogo anteriores. **Actualizar modelos** consulta de nuevo la lista sin borrar las opciones de modelos que hayas personalizado.

Abre el selector de modelos y elige uno disponible. El alias inicial de Zylon es `zylon/default`.

## 4. Prueba una tarea pequeña

Selecciona una carpeta de proyecto y envía:

> Enumera los archivos de la carpeta principal del proyecto. Lee un archivo de texto pequeño y resume para qué sirve. No modifiques archivos ni instales nada.

Contrasta el resultado con los archivos de tu ordenador. La licencia permite utilizar la aplicación; la consulta de modelos comprueba la conexión; esta tarea confirma que el modelo seleccionado puede responder y usar una herramienta.

Guarda la clave en su campo de credenciales. Continúa con [Tu primera tarea](/zylon-code/es/getting-started/first-task), o consulta [problemas de conexión](/zylon-code/es/troubleshooting/setup-and-models) si falla algún paso.
