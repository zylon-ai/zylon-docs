Knowledge base permissions are governed by **project roles**:

- **Viewer** — can start chats and AI Documents that *use* the Knowledge Base; **cannot** modify the Knowledge Base.
- **Editor** — can **add/remove** Knowledge Base content and structure.
- **Admin / Owner** — full control; can also **transfer ownership**.

If you're a Viewer and need files added to the Knowledge Base, ask a project Editor or Admin to add them. If you need to edit the Knowledge Base yourself, ask the project owner or an Admin to review your project role. You can also ask them to confirm your current role; the project view may not display it.
