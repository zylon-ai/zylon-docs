Descarga Zylon Code desde el Backoffice de tu organización e instálalo en tu ordenador. Tus proyectos pueden necesitar herramientas adicionales para compilar código o ejecutar pruebas.

## Antes de descargar

Pide al administrador el **dominio de Zylon**, por ejemplo `https://zylon.example`, y confirma que la instalación tiene una licencia vigente que incluye Zylon Code. También necesitarás una clave de API de un gateway para utilizar sus modelos. Son requisitos distintos; [Licencia y acceso](/zylon-code/es/getting-started/license-and-access) explica cada uno.

## Descarga desde Backoffice

Si tienes acceso al área **Plataforma**:

1. Inicia sesión en el Backoffice de tu organización.
2. Abre **Plataforma → Puertas de enlace**.
3. Pulsa **Descargar Zylon Code**.
4. Descarga el instalador correspondiente a tu sistema operativo y a la arquitectura del procesador.

El área Plataforma está disponible para cuentas con acceso de Operador o SuperAdmin. Si tienes acceso como desarrollador, también encontrarás la descarga de Zylon Code en las instrucciones que aparecen justo después de crear una clave de API de un gateway. Sigue [Crea una clave de API del gateway](/zylon-code/es/getting-started/connect-to-zylon#2-crea-una-clave-de-api-del-gateway) para encontrar esa descarga.

La tarjeta de descarga muestra la versión y la arquitectura disponibles. Si puede identificar tu dispositivo, selecciona una versión compatible; si no, elige en **Otras plataformas**. Comprueba la arquitectura: `arm64` corresponde a procesadores ARM, incluidos los Apple Silicon; `x64`, a procesadores Intel o AMD de 64 bits. Utiliza una versión que se ofrezca para tu sistema.

Los instaladores disponibles dependen de lo que publique tu organización. Si no aparece la descarga, pide al administrador que revise tu acceso a Backoffice y los instaladores publicados.

## Instala y abre la aplicación

Abre el instalador o el archivo descargado y sigue las instrucciones de instalación que acompañen a esa versión. Al abrir Zylon Code por primera vez, introduce el dominio de Zylon en la pantalla de bienvenida. La aplicación comprobará que tu organización tiene una licencia vigente. Continúa con [Conectar con Zylon](/zylon-code/es/getting-started/connect-to-zylon) para completar la conexión y elegir un modelo.

Una vez terminada la configuración, puedes elegir español o inglés en **Ajustes → General**. Cerrar la ventana principal puede dejar la aplicación funcionando en segundo plano; utiliza **Salir** cuando quieras detenerla por completo.

Si la aplicación no se abre, consulta [problemas de inicio](/zylon-code/es/troubleshooting/setup-and-models).
