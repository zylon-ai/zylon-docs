Ask Zylon Code to create Word documents, spreadsheets or presentations from your project files. The result depends on the skills and document tools included in your Desktop build.

## Describe the deliverable

> Create an XLSX summary from the CSV files in reports/. Keep the originals unchanged. Include source filenames, totals calculated with formulas and a summary sheet. Deliver the editable workbook and explain how you checked it.

Specify the input files, output format, content and checks. Document workflows may use the `office-docx`, `office-pptx` and `office-xlsx` skills. If a required capability is absent, ask the agent to identify it before installing anything.

## Preview the output

Open the generated file in the right panel or its usual application. Word and PowerPoint previews use local PDF conversion; spreadsheets have their own viewer.

These panels also display project reports in formats such as HTML. If a report needs scripts, check **Settings → General → Developer view**; HTML preview behavior follows that setting. If Diff Review opens a menu from the file card, choose **Open as usual** for the document preview.

Check pages, slides, formulas and totals. File validation can confirm structure and content without verifying layout or recalculated formulas. Ask for a PDF export or recalculation when your task requires them.

Visual inspection by the agent needs a working preview and a model that supports images. If preview fails, keep the editable source and consult [tool troubleshooting](/zylon-code/troubleshooting/tools-and-permissions).
