Zylon Code se distribuye como una aplicación de escritorio ya compilada. Para instalarla no necesitas clonar el repositorio ni instalar Node, Python o un gestor de paquetes.

<Note>
Añadiremos aquí el enlace de descarga y los pasos de instalación cuando esté preparada la distribución para clientes. Mientras tanto, utiliza la aplicación y las instrucciones que te facilite tu contacto de Zylon.
</Note>

## Antes de empezar

Ten preparada una carpeta de proyecto. Para conectarte a través del gateway de tu organización, pide al administrador la **URL base** y un **token de desarrollador del gateway**. Puedes abrir la aplicación antes de configurar un modelo.

## Abre la aplicación

Abre Zylon Code y completa la configuración de bienvenida. Una instalación nueva empieza en español; puedes cambiar a inglés en **Ajustes → General**. Deberías ver el selector de proyecto, la zona de conversación y los ajustes.

Cerrar la ventana principal puede dejar la aplicación funcionando en segundo plano. Utiliza la opción **Salir** del sistema operativo cuando quieras detenerla por completo.

Continúa con [Conectar con Zylon](/zylon-code/es/getting-started/connect-to-zylon). Si la aplicación no se abre, consulta [problemas de inicio](/zylon-code/es/troubleshooting/setup-and-models).
