Inspect the current state before repeating interrupted work. A disconnected interface does not mean a command stopped, and cancelling a task does not roll back files.

## Reconnect

Use the retry action beside Settings if the interface reports disconnection. If it remains disconnected, quit the application completely and reopen it. Keep any error for support. Avoid resetting the data folder just to repair a connection.

If the mandatory domain dialog appears, follow [License and access](/zylon-code/getting-started/license-and-access). It is separate from a disconnected interface. Resolve it before resuming; it does not undo edits or terminate every previously started command.

## Check interrupted work

Review current files, Git changes, job status and the last recorded tool result. External browser tabs and login state may need restoring after a provider restart.

Give the agent the facts:

> The run stopped after editing config.ts. Read the current file and inspect the last recorded command. Explain what remains before repeating writes or installing anything.

## Report a problem

Include the application version, operating system and architecture, selected mode, provider/model, affected plugin, reproduction steps and exact error. Remove credentials and private data from logs, screenshots and conversation exports before sharing them.

Preserve original records and share a sanitized copy. If recovery will change stored data, back it up first; [Data and backups](/zylon-code/configuration/data-and-backups) explains what to retain.
