Abre **Ajustes → Modelos** para configurar una conexión. Para el gateway de tu empresa, sigue [Conectar con Zylon](/zylon-code/es/getting-started/connect-to-zylon). Las tarjetas de otros proveedores y las conexiones personalizadas dependen de la versión de la aplicación.

## Utiliza un proveedor de la lista

Abre su tarjeta, introduce la clave API y guarda. El campo de la clave empieza vacío; si lo dejas así al editar, se conserva la clave guardada. Después selecciona un modelo y prueba una tarea pequeña.

Modifica la URL o la lista de modelos solo si la tarjeta ofrece esos controles y el proveedor lo requiere.

## Conecta un servicio personalizado o local

1. Añade un proveedor personalizado con un identificador único y un nombre reconocible.
2. Introduce su **URL base** y el protocolo de API que admita el servidor.
3. Introduce la clave, si la necesita, en su campo de credenciales.
4. Pulsa **Obtener modelos disponibles**, selecciona los que quieras y guarda. Si falla la consulta, añade a mano los identificadores exactos del servidor.
5. Selecciona un modelo y pídele una tarea pequeña de solo lectura que utilice una herramienta.

**Chat Completions**, **Responses** y **Anthropic Messages** son protocolos de API distintos. Elige el que implemente el servidor; decir «compatible con OpenAI» no basta para saber cuál utilizar.

Un modelo local necesita un servidor de modelos funcionando por separado y accesible desde tu ordenador. En una URL de conexión, `localhost` se refiere a este ordenador.

## Comprueba las capacidades del modelo

Una conexión puede ofrecer modelos con y sin razonamiento. Selecciona primero el modelo y comprueba si su menú del cuadro de mensajes muestra **Esfuerzo**. Actualiza la lista cuando el servidor cambie las capacidades anunciadas. Los niveles pertenecen a cada modelo; no son un ajuste común a todos los proveedores. Consulta [Capacidades de razonamiento](/zylon-code/es/models/model-options) para conocer los detalles.

## Modifica o elimina una conexión

Eliminar un proveedor puede dejar sin servicio el modelo guardado en una conversación. Selecciona otro si ocurre. [Opciones de modelos](/zylon-code/es/models/model-options) explica las capacidades de imagen y contexto; [diagnóstico](/zylon-code/es/troubleshooting/setup-and-models) te ayuda con los errores de conexión.
