La barra izquierda contiene tus proyectos y conversaciones. En el centro están la conversación y el cuadro donde escribes los mensajes. Los paneles de la derecha permiten abrir archivos, revisar resultados y utilizar un terminal o un navegador.

| Zona | Qué puedes hacer |
| --- | --- |
| Proyectos y chats | Seleccionar un proyecto, iniciar chats, buscar, fijar, renombrar, bifurcar o archivar. |
| Cuadro de mensajes | Escribir una petición, adjuntar archivos y elegir modelo, modo y permisos. |
| Selector de modelo | Elegir el modelo que atenderá la siguiente petición. |
| Selector de modo | Elegir las capacidades del agente para una tarea nueva. |
| Selector de permisos | Establecer el acceso y revisar solicitudes de autorización. |
| Tarjetas de herramientas | Consultar qué ha pedido el agente, qué se ha ejecutado y cuál ha sido el resultado. |
| Paneles derechos | Explorar archivos, revisar entregables y ejecutar tus propios comandos. |
| Plugins | Activar funciones y configurar integraciones. |
| Ajustes | Cambiar idioma, apariencia, conexiones de modelos y valores predeterminados. |

## Escribe una petición

Pulsa **+** o escribe `/` para abrir el menú de adjuntos, comandos y habilidades disponibles. Escribe `@` para seleccionar archivos, carpetas o servidores MCP activados. Las opciones dependen del modo y los plugins que estés utilizando.

## Sigue el trabajo

Despliega una tarjeta de herramienta para ver sus parámetros, el resultado o un error. La preferencia de detalle del trabajo cambia cuánta información del proceso se muestra. Las preguntas y las autorizaciones aparecen con controles para responder.

Continúa con [Proyectos](/zylon-code/es/everyday-use/projects) y sigue las páginas de uso diario en orden. Puedes consultar los [atajos de teclado](/zylon-code/es/reference/keyboard-shortcuts) cuando los necesites.
