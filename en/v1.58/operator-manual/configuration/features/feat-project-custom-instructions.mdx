---
title: "Workspace Customization"
---

Configure Workspace limits for uploaded documents and project custom instructions.

Users can customize project instructions from the project settings dialog, as explained in [Adding custom instructions](/en/v1.58/user-manual/adding-custom-instructions). These instructions are applied at the project level and influence how Zylon responds in chats.

### Configuration

Use the following keys in your Helm `values.yaml` to control the maximum document size and the maximum instructions length:

```yaml
features:
  maxArtifactSizeMB: "250"
  maxInstructionsLength: 4000
```

Apply the values through your normal Helm deployment or upgrade process.

### Configuration details

| Key | Default | Values | Description |
| --- | --- | --- | --- |
| `maxArtifactSizeMB` | `"250"` | Positive integer, as a string | Maximum size per document in MiB. The default is 250 MiB, or 262,144,000 bytes |
| `maxInstructionsLength` | `4000` | Positive integer | Maximum instructions length accepted by both the Workspace UI and the API |
