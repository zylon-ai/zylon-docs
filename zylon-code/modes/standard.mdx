Standard is the default Zylon mode. The agent calls tools directly to read and edit files, search and run commands. It includes project instructions, skills, planning, goals, subagents, workflows and context compaction.

## Start a task

Select Standard before the first message. State the desired outcome, relevant files, restrictions and how to check the result:

> Find why submitting the search form twice clears the results. Fix the cause, run the relevant existing tests and explain the changed files. Ask before installing dependencies.

Expected evidence is the investigation, a focused code change and actual test output. Review the changed-files card and tool results before accepting the answer.

## More than coding

Standard can also summarize notes, create deliverables and write batch scripts. PTC is not required just because the task processes many files. Optional browser, computer, search and MCP capabilities require their own setup; selecting Standard does not install them.

Use [Plan mode](/zylon-code/modes/plan-mode) when you want a proposal first. Use [project instructions](/zylon-code/customization/project-instructions) for repository conventions and [delegation](/zylon-code/agents/delegation) for independent subtasks. Tools remain subject to the selected permissions and external prerequisites.
