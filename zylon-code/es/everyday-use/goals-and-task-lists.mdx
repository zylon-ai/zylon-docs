Un **objetivo** indica al agente qué resultado debe seguir buscando. Una **lista de tareas** muestra los pasos que está dando para alcanzarlo. Son útiles cuando el trabajo dura varios turnos y quieres tener claro su progreso.

## Define un objetivo

Selecciona **Objetivo** en el menú del cuadro de mensajes o escribe `/goal`. Indica el resultado y cómo se sabrá que está terminado:

> Actualiza la guía de configuración para que coincida con el código que lee esa configuración. Termina cuando hayas revisado todos los campos documentados y se superen las comprobaciones de la documentación.

La barra de objetivo permite consultar el progreso, pausar o reanudar, editar el objetivo y quitarlo. Quitarlo mantiene la conversación y los archivos. Zylon Code debe seguir abierto para que el agente pueda continuar.

## Consulta la lista de tareas

En los modos compatibles, el agente puede mantener pasos pendientes, en curso y completados. Utiliza la lista para seguir el trabajo y después revisa los resultados de las herramientas y los archivos. Si cambia lo que quieres conseguir, actualiza el objetivo para evitar instrucciones contradictorias. Si parece que el trabajo se ha detenido, comprueba si el agente espera una respuesta, un permiso o el resultado de una herramienta antes de pedirle que continúe.

Un [plan](/zylon-code/es/modes/plan-mode) es una propuesta que revisas antes de implementar. Una [tarea automatizada](/zylon-code/es/plugins/automation-tasks) programa trabajo futuro. Utiliza esas funciones cuando quieras aprobar primero una propuesta o ejecutar una tarea más adelante.
