Mínimo incluye una shell persistente y unas instrucciones de sistema fijas. Está pensado para tareas pequeñas y comparaciones controladas. No carga automáticamente las instrucciones del proyecto, habilidades, planificación, objetivos ni compactación de los modos más completos.

## Utilízalo para una tarea sencilla

Por ejemplo:

> Ejecuta las pruebas existentes de este módulo, identifica el comportamiento que falla y explica la causa. No edites archivos ni instales paquetes.

Consulta los comandos y sus resultados. La shell puede leer, escribir y ejecutar scripts si los permisos lo permiten; disponer de menos herramientas no hace que el modo sea automáticamente más seguro.

Si el repositorio tiene reglas en `AGENTS.md`, facilítalas en la petición o utiliza Estándar, que sí incluye su lectura automática.

## Compara en las mismas condiciones

Para comparar con otro modo, mantén el modelo, permisos, petición y archivos iniciales. Abrir un chat nuevo no restaura los archivos de un intento anterior.

Para trabajo habitual o largo, empieza por [Estándar](/zylon-code/es/modes/standard). Si necesitas una selección distinta de herramientas, puedes [crear un modo personalizado](/zylon-code/es/customization/custom-modes).
