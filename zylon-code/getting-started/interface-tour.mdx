The left sidebar contains your projects and conversations. The center shows the conversation and the message box. The right panels let you open files, review outputs and use a terminal or browser.

| Area | What you can do |
| --- | --- |
| Projects and conversations | Open a project, start a conversation and find earlier work. |
| Message box | Write a request, attach files and choose model, mode and permissions. |
| Model picker | Choose which model will handle the next request. |
| Mode picker | Choose how the agent works on a new task. Start with Standard. |
| Permission picker | Choose what the agent may do, such as read files or edit the project. |
| Tool cards | See what the agent requested, what ran and what it returned. |
| Right panels | Open files, review results and run your own terminal commands. |
| Plugins | Enable features and configure integrations. |
| Settings | Change language, appearance, model connections and defaults. |

To change the Zylon domain, open **Settings → General**. To update the API key or model connections, open **Settings → Models**. See [Settings](/zylon-code/configuration/settings) for other options.

## Write a task

Use **+** to open the attachment menu. Type `/` to see available commands and skills, or `@` to reference files, folders or connected MCP servers. [MCP servers](/zylon-code/plugins/mcp) connect the agent to additional tools and services. The options depend on your selected mode and plugins.

## Follow a task

Expand a tool card to see which file the agent read, which command it ran or what result it received. If it asks a question or requests permission, read the request and respond using the controls shown. You can [stop a task or give new instructions](/zylon-code/everyday-use/conversations) while it works.

Continue with [Projects](/zylon-code/everyday-use/projects), then follow the daily-use pages in order. [Keyboard shortcuts](/zylon-code/reference/keyboard-shortcuts) provides a reference when you need it.
