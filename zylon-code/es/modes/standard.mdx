Estándar es el modo predeterminado de Zylon Code. El agente utiliza herramientas para leer y editar archivos, buscar y ejecutar comandos. Incluye instrucciones del proyecto, habilidades, planificación, objetivos, agentes secundarios, flujos de trabajo y compactación del contexto.

## Empieza una tarea

Selecciona Estándar antes del primer mensaje. Explica qué quieres conseguir, qué archivos son relevantes, las restricciones y cómo comprobar el resultado:

> Investiga por qué enviar dos veces el formulario de búsqueda borra los resultados. Corrige la causa con un cambio pequeño, ejecuta las pruebas existentes de ese comportamiento y explica qué has modificado. Pregunta antes de instalar dependencias.

El resultado debería incluir la investigación, los cambios y la salida de las pruebas. Revisa las tarjetas de herramientas y los archivos modificados.

## También sirve para otras tareas

Estándar puede resumir notas, crear entregables y escribir scripts para procesar archivos. No necesitas PTC por el mero hecho de trabajar con muchos archivos. Las funciones opcionales, como búsqueda web, automatización del navegador y MCPs, necesitan su propia configuración.

Utiliza [planificación](/zylon-code/es/modes/plan-mode) cuando quieras revisar una propuesta antes de implementar, [instrucciones del proyecto](/zylon-code/es/customization/project-instructions) para las convenciones del repositorio y [delegación](/zylon-code/es/agents/delegation) para subtareas independientes.
